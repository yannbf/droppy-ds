### The focus ring

`--ds-shadow-focus` is a single design principle — one two-layer focus ring reused everywhere
`:focus-visible` needs an outline — composed from two semantic color tokens rather than hardcoded
colors:

```css
--ds-shadow-focus: 0 0 0 1px var(--ds-color-focus-ring), 0 0 0 4px var(--ds-color-focus-halo);
```

It stacks two `box-shadow` rings: an inner 1px solid ring in `--ds-color-focus-ring`, and an outer
4px halo in `--ds-color-focus-halo`, both centered on the element with no offset. In dark mode the
inner ring widens to 2px:

```css
--ds-shadow-focus: 0 0 0 2px var(--ds-color-focus-ring), 0 0 0 4px var(--ds-color-focus-halo);
```

Every focusable part in the theme layer applies it the same way, on `:focus-visible`:

```css
.Button:focus-visible {
  outline: none;
  box-shadow: var(--ds-shadow-focus);
}
```

## Motion

Two duration steps beyond the base, one shared easing:

<TokenSection title="Durations">
  <MotionDemo durationToken="--ds-motion-fast" />
  <MotionDemo durationToken="--ds-motion-base" />
  <MotionDemo durationToken="--ds-motion-slow" />
</TokenSection>

`--ds-motion-ease` (`ease-in`) is the one easing curve used across every transition in the theme
layer — hover states at `--ds-motion-fast` (150ms), the theme cross-fade and overlay transitions
at `--ds-motion-base` (250ms) and `--ds-motion-slow` (300ms).

The theme stylesheet has no `prefers-reduced-motion` handling of its own — that media query
isn't referenced anywhere in `src/theme/styles.css`. Where reduced motion is respected (the
`Skeleton` and `Spinner` components), it's implemented per component, not as a shared token or
global rule.
