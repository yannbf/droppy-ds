## Breakpoints

| Token | Value |
| --- | --- |
| `--ds-breakpoint-sm` | 640px |
| `--ds-breakpoint-md` | 768px |
| `--ds-breakpoint-lg` | 1024px |
| `--ds-breakpoint-xl` | 1440px |

These four are documented reference values, not something CSS can consume directly — a custom
property can't be read inside a `@media` query. The stylesheet itself doesn't reference them
anywhere; components that need a breakpoint (`Container`, `PageSection`) hardcode the matching
literal pixel value in their own `@media` rule and leave a comment pointing back at the token
it matches, e.g. `/* 640px matches --ds-breakpoint-sm; media queries can't read custom
properties. */`. Treat these as the source of truth for which literal to hardcode, and keep the
comment in place if you add a new responsive rule.
