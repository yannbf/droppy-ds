# Colors

Droppy's color system has two layers. **Palette primitives** (`--ds-palette-*`) are the raw
color values — a neutral scale plus a handful of accent scales. **Semantic roles**
(`--ds-color-*`) point at a primitive for a specific purpose — a surface, a piece of text, a
border. Everyday component work should reach for a semantic role; drop down to a palette
primitive only when you're defining a new semantic role, not when styling a screen.

This page reads every swatch from `var(--ds-color-*)` and `var(--ds-palette-*)` and recomputes
the value shown under each swatch whenever `data-theme` changes on the document root — flip the
**Theme** toolbar above to see it happen live.

Primitives never change between themes — only the semantic roles that point at them do.

## Dark mode

`html[data-theme='dark']` overrides the semantic layer only — every `--ds-color-*` role above
is redefined in full for dark mode, while the `--ds-palette-*` primitives it points at stay the
same values in both themes. A `prefers-color-scheme: dark` media query provides the same dark
values as a fallback for any context that never sets `data-theme` explicitly.
