# Typography

## Families

Two font families: `Montserrat` for headings, `Hind` for body copy. Both declare their own web
fallback stack.

<TokenRow token="--ds-type-family-heading" renderSample={(t) => <span style={{ fontFamily: `var(${t})`, fontSize: '1.5rem', fontWeight: 700 }}>Montserrat heading</span>} />
<TokenRow token="--ds-type-family-body" renderSample={(t) => <span style={{ fontFamily: `var(${t})`, fontSize: '1.125rem' }}>Hind body copy</span>} />

## Tracking

There is no dedicated leading/line-height token group in the stylesheet — line-heights are set
per component (e.g. `1.25rem` on `.TabsTab`), not tokenized. Letter-tracking is tokenized:
