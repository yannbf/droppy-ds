# Color tokens

**Palette primitives** (`ds.palette.*`) are the raw color values used in Droppy.
**Semantic roles** (everything else under `ds.color.*`) serve specific purposes,
like a surface, a piece of text, a border. Everyday component work should only use
semantic colors. Semantic colors ensure consistent branding, and provide dark theme
support.

## Semantic roles

Each role resolves to one of the colors in the primitive palettes below, depending on whether the `light` or `dark` mode is used.
