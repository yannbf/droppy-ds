# Spacing and layout tokens

This page lists all tokens related to spacing your components. The list is voluntarily short to encourage consistent layouts. If you have a need that is not covered by the existing tokens, please make a request for new tokens to be added.

## Space scale

The Droppy space scale acts as a ladder, with no particular semantic attributed to individual token values.

## Radius

Radius expresses the "floatiness" of different UI elements. The more elevated or overlay-like a surface, the larger the radius.

- **control:** buttons, inputs, checkboxes, radios, toggles
- **card:** cards, tooltips, and other floating chrome
- **sheet:** dialog, drawer
- **pill:** switch track
- **round:** avatar, radio, switch thumb
