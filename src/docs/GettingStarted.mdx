# Getting started

`@droppy/design-system` is the Droppy design language for developers. It provides React
implementations of Droppy components, and a CSS theme. Base UI is used under the hood, but
Droppy components are themed rather than headless. Base UI cannot be used interchangeably.

## Install

Install through NPM. `@base-ui/react`, `react`, and `react-dom` are peer dependencies, so install them alongside:

```bash
npm install "@droppy/design-system @base-ui/react react react-dom
```

To use a specific commit SHA, install Droppy from [pkg.pr.new](https://pkg.pr.new):

```bash
npm install "@droppy/design-system@https://pkg.pr.new/yannbf/droppy-ds/@droppy/design-system@<sha>"
```

## Import stylesheet

Once, in your app entry, import the CSS file. It carries the Droppy tokens and every component's styles.

```tsx
import '@droppy/design-system/styles.css'
```

## Use components

Then import components anywhere. No need for `className` props:

```tsx
import { Button, Input, Modal } from '@droppy/design-system'

export const RemoveItem = ({ isOpen, onClose }) => (
  <Modal isOpen={isOpen} onClose={onClose}>
    <Input label="Reason" />
    <Button large>Remove</Button>
  </Modal>
)
```
