# Typography tokens

The Droppy type scale is organised in two families: the `Montserrat` font for headings and brand wordmark, and the `Hind` font for body copy, labels, and UI text, as per the [Droppy brand
guidelines](?path=/docs/brand-guidelines--docs).

<TypographyScale />

Each step carries a default weight — bold for the heading steps, regular for the rest — but that default is not prescriptive: override it to mix bold and regular within a paragraph or heading. The Display font supports 400, 500, 600, and 700 weights; the Body font supports 400 and 500 weights. All typography uses a `normal` leading.
