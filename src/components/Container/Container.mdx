# Container

{/* BEGIN: anatomy */}

## Anatomy

`Container` is a single-part component: one `<div>` that bounds the page width. It adds no layout of its own inside — children render in normal flow.

<Canvas of={ContainerStories.Anatomy} />

| Part | `data-part` | Renders | Purpose                                                  |
| :--- | :---------- | :------ | :------------------------------------------------------- |
| Root | `root`      | `<div>` | The max-width bound, the centering, and the side padding |

{/* END: anatomy */}

{/* BEGIN: a11y */}

## Keyboard & screen reader

`Container` is a non-interactive layout element — there is no keyboard interaction to document.

- **ARIA:** none — a plain wrapping `<div>`.
- **Screen reader:** not announced as a distinct region; its children are read in document order.
