# Container

{/* BEGIN: when-to-use */}

## When to use

- Wrapping a page's main content so it caps at a readable width and doesn't touch the viewport
  edges on desktop.
- `desktopOnly` for a section that already owns its mobile padding (a hero, a banner) and only
  needs the width cap once the layout goes multi-column.

## When not to use

- Inside a component that already manages its own width — nesting `Container` inside `Container`
  compounds the padding instead of replacing it.
- For a raised surface that groups content — use [Card](?path=/docs/media-content-card--docs)
  instead; `Container` has no background, radius, or shadow.

{/* END: when-to-use */}

{/* BEGIN: anatomy */}

## Anatomy

`Container` is a single-part component: one `<div>` that bounds the page width. It adds no layout of its own inside — children render in normal flow.

<Canvas of={ContainerStories.Anatomy} />

| Part | `data-part` | Renders | Purpose                                                  |
| :--- | :---------- | :------ | :------------------------------------------------------- |
| Root | `root`      | `<div>` | The max-width bound, the centering, and the side padding |
