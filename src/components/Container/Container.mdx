# Container

## Anatomy

`Container` is a single-part component: one `<div>` that bounds the page width. It adds no layout of its own inside — children render in normal flow.

<Canvas of={ContainerStories.Anatomy} />

| Part | `data-part` | Renders | Purpose                                                  |
| :--- | :---------- | :------ | :------------------------------------------------------- |
| Root | `root`      | `<div>` | The max-width bound, the centering, and the side padding |

## API reference

<ArgTypes of={ContainerStories} />

### `children`

Rendered in normal flow; the wrapper only bounds the width.

<Canvas of={ContainerStories.Children} />

### `desktopOnly`

Below 1024px, `Container` renders with no width cap and no padding of its own. From 1024px up, it
behaves exactly like the default. This covers what Mealdrop's second global `.container-desktop`
class did, named for what it does rather than for the old suffix.

<Canvas of={ContainerStories.DesktopOnly} />

### `className`

Merged onto the root alongside the component's own `droppy-Container` class.
