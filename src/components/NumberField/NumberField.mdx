# NumberField

{/* BEGIN: anatomy */}

## Anatomy

A `Field` wrapper for the label association, a scrub area holding the label, and a group of decrement, input, and increment. The label being inside the scrub area is what makes dragging it change the value.

<Canvas of={NumberFieldStories.Anatomy} />

| Part       | `data-part` | Renders    | Purpose                                             |
| :--------- | :---------- | :--------- | :-------------------------------------------------- |
| Field      | `field`     | `<div>`    | Base UI's `Field.Root`, associating label and input |
| Root       | `root`      | `<div>`    | Owns the value, the bounds, and the formatting      |
| Scrub area | `scrub`     | `<span>`   | Wraps the label; dragging it steps the value        |
| Label      | `label`     | `<label>`  | The visible label and accessible name               |
| Group      | `group`     | `<div>`    | Holds the buttons and the input                     |
| Decrement  | `decrement` | `<button>` | Disabled at `min`                                   |
| Input      | `input`     | `<input>`  | The typeable control                                |
| Increment  | `increment` | `<button>` | Disabled at `max`                                   |

{/* END: anatomy */}

## Keyboard & screen reader

| Key / interaction                     | Context | Action                                             |
| ------------------------------------- | ------- | -------------------------------------------------- |
| Arrow Up / Arrow Down (input focused) | any     | Steps the value by `step`                          |
| Home / End (input focused)            | any     | Jumps to `min`/`max`, when set                     |
| Type digits                           | any     | Replaces the value as parsed input                 |
| Click Increment / Decrement           | any     | Steps the value by `step`; disables at `min`/`max` |
| Drag the label                        | any     | Scrubs the value with pointer movement             |

- **ARIA:** the increment and decrement buttons carry their own accessible names ("Increase" /
  "Decrease") from Base UI; the input is a `textbox` associated with the label through `Field`.
- **Screen reader:** the current value is read as the input's own value; the stepper buttons
  announce as disabled once a bound is reached.
- **You must provide:** `label` — without it the field has no accessible name.
