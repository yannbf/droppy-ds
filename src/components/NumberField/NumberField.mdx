# NumberField

A typeable numeric input with increment/decrement buttons and pointer scrub, for a quantity or
amount that also needs a keyboard or direct-entry path.

- **Import:** `import { NumberField } from '@droppy/design-system'`
- **Built on:** Base UI [`NumberField`](https://base-ui.com/react/components/number-field),
  labelled via [`Field`](https://base-ui.com/react/components/field) the same way
  [Input](?path=/docs/components-input--docs) is.

<Canvas of={NumberFieldStories.Default} />

## Features

- **Typeable, unlike a plain stepper.** Type a value directly, use the arrow keys, click the
  increment/decrement buttons, or drag the label to scrub — four ways to reach the same value.
- **`min`/`max`/`step` clamp interactive changes.** The stepper buttons disable once a bound is
  reached rather than wrapping around.
- **The label doubles as a scrub area.** Dragging it left/right changes the value with the
  pointer, without needing to focus the input first.
- **`value`/`defaultValue`/`onValueChange` follow Base UI's controlled/uncontrolled pattern** —
  omit `value` for an uncontrolled field, or pass both `value` and `onValueChange` to control it.
- Merges any incoming `className` onto the root, alongside the theme layer's own class.

## When to use

- A quantity or amount where the caller can't predict every value in advance, or where keyboard
  and direct-entry access matter — a cart quantity with a wide range, a price, a form field
  counting units of something.

## When not to use

- A small, bounded range where tap-tap increments are the whole interaction and typing isn't
  expected — reach for [QuantityStepper](?path=/docs/components-quantitystepper--docs) instead;
  it is the simpler, button-only sibling of this component.

## Keyboard & screen reader

| Key / interaction                    | Context | Action                                             |
| ------------------------------------- | ------- | --------------------------------------------------- |
| Arrow Up / Arrow Down (input focused) | any     | Steps the value by `step`                          |
| Home / End (input focused)            | any     | Jumps to `min`/`max`, when set                      |
| Type digits                           | any     | Replaces the value as parsed input                 |
| Click Increment / Decrement           | any     | Steps the value by `step`; disables at `min`/`max` |
| Drag the label                        | any     | Scrubs the value with pointer movement             |

- **ARIA:** the increment and decrement buttons carry their own accessible names ("Increase" /
  "Decrease") from Base UI; the input is a `textbox` associated with the label through `Field`.
- **Screen reader:** the current value is read as the input's own value; the stepper buttons
  announce as disabled once a bound is reached.
- **You must provide:** `label` — without it the field has no accessible name.

## Styling

Colors, spacing, and the scrub cursor come entirely from the theme layer's `NumberField*`
classes — this component adds no styling of its own beyond forwarding `className` to the root.
