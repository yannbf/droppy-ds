# NumberField

{/* BEGIN: general */}

A typeable numeric input with increment/decrement buttons and pointer scrub, for a quantity or
amount that also needs a keyboard or direct-entry path.

```tsx
import { NumberField } from '@droppy/design-system'
```

labelled via [`Field`](https://base-ui.com/react/components/field) the same way
[Input](?path=/docs/forms-input-input--docs) is.

<Canvas of={NumberFieldStories.Default} />

## Features

- **Typeable, unlike a plain stepper.** Type a value directly, use the arrow keys, click the
  increment/decrement buttons, or drag the label to scrub — four ways to reach the same value.
- **`min`/`max`/`step` clamp interactive changes.** The stepper buttons disable once a bound is
  reached rather than wrapping around.
- **The label doubles as a scrub area.** Dragging it left/right changes the value with the
  pointer, without needing to focus the input first.
- **`value`/`defaultValue`/`onValueChange` follow Base UI's controlled/uncontrolled pattern** —
  omit `value` for an uncontrolled field, or pass both `value` and `onValueChange` to control it.
- Merges any incoming `className` onto the root, alongside the theme layer's own class.

{/* END: general */}

## How it works

Three ways in, not one: type a value, press the buttons, or drag the label itself — the scrub area
sits behind the label text. That third route is what separates this from
[QuantityStepper](?path=/docs/forms-input-quantitystepper--docs), which only does tap-tap
increments.

## Anatomy

A `Field` wrapper for the label association, a scrub area holding the label, and a group of decrement, input, and increment. The label being inside the scrub area is what makes dragging it change the value.

<Canvas of={NumberFieldStories.Anatomy} />

| Part       | `data-part` | Renders    | Purpose                                             |
| :--------- | :---------- | :--------- | :-------------------------------------------------- |
| Field      | `field`     | `<div>`    | Base UI's `Field.Root`, associating label and input |
| Root       | `root`      | `<div>`    | Owns the value, the bounds, and the formatting      |
| Scrub area | `scrub`     | `<span>`   | Wraps the label; dragging it steps the value        |
| Label      | `label`     | `<label>`  | The visible label and accessible name               |
| Group      | `group`     | `<div>`    | Holds the buttons and the input                     |
| Decrement  | `decrement` | `<button>` | Disabled at `min`                                   |
| Input      | `input`     | `<input>`  | The typeable control                                |
| Increment  | `increment` | `<button>` | Disabled at `max`                                   |

{/* END: anatomy */}
