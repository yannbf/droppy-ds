## API reference

<ArgTypes of={CardStories} />

### `children`

Compose freely — `Card` provides the surface and nothing else.

<Canvas of={CardStories.Children} />

### `padded`

Adds `--ds-space-sm` on all sides. Bare by default, since most of the components it replaces
already own their internal padding.

<Canvas of={CardStories.Padded} />

### `interactive`

Appearance only: a pointer cursor and a hover dim. It wires no `onClick`, `role`, or `tabIndex` —
compose the interactive semantics yourself, or wrap the card in a real control.

<Canvas of={CardStories.Interactive} />

### `className`

Merged onto the root alongside the component's own `droppy-Card` class.

<Canvas of={CardStories.ClassName} />
