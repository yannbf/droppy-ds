# Card

{/* BEGIN: general */}

A rounded, clipped surface for grouping content: a restaurant tile, a food item, an order summary.

```tsx
import { Card } from '@droppy/design-system'
```

<Canvas of={CardStories.Default} />

## Features

- Deliberately minimal: background, radius, and clipping only — no layout, image slot, or
  title slot. Callers compose those from their own markup and Droppy's other components.
- No resting shadow. A card that should lift adds it at the call site — for example
  `box-shadow: var(--ds-shadow-lift)` on hover, the treatment food-item tiles use.
- `padded` adds `--ds-space-sm` padding on all sides; unset, the shell is bare, since most of the
  components it replaces already own their internal padding.
- `interactive` adds a pointer cursor and a hover dim — the shell only. It wires no `onClick`;
  callers compose the click handling themselves.
- `overflow: hidden`, so an edge-to-edge image child clips to the card's own corner radius instead
  of squaring off past it.
- Merges any incoming `className` with its own `droppy-Card` class.

## Anatomy

`Card` is a single-part component: one `<div>` that provides the surface, with children in normal flow. There are deliberately no slots — no image, title, or footer part — so the composition inside belongs entirely to the caller.
