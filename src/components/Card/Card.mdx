# Card

{/* BEGIN: when-to-use */}

## When to use

- A tile or panel that groups related content and should read as a single surface — a grid
  item, a summary block, a preview card.

## When not to use

- An overlay that blocks or floats above the page — use [Modal](?path=/docs/overlays-modal--docs)
  for a blocking decision or [Sidebar](?path=/docs/overlays-sidebar--docs) for a panel reviewed
  alongside the page. `Card` has no portal, backdrop, or dismissal behavior.

{/* END: when-to-use */}

{/* BEGIN: anatomy */}

## Anatomy

`Card` is a single-part component: one `<div>` that provides the surface, with children in normal flow. There are deliberately no slots — no image, title, or footer part — so the composition inside belongs entirely to the caller.

<Canvas of={CardStories.Anatomy} />

| Part | `data-part` | Renders | Purpose                                                                                |
| :--- | :---------- | :------ | :------------------------------------------------------------------------------------- |
| Root | `root`      | `<div>` | The surface: background, radius, resting shadow, and the clipping that keeps images in |
