# Link

{/* BEGIN: when-to-use */}

## When to use

- A link inside a sentence, a paragraph, or a short inline list of related links.

## When not to use

- A primary or secondary action a visitor is meant to notice and act on — use
  [Button](?path=/docs/actions-button--docs) instead.
- A trail of ancestor pages — use [Breadcrumb](?path=/docs/navigation-breadcrumb--docs).

{/* END: when-to-use */}

{/* BEGIN: anatomy */}

## Anatomy

`Link` is a single-part component. By default it renders an `<a>`; with `render` it clones the element you pass, so the part is whatever your router link renders.

<Canvas of={LinkStories.Anatomy} />

| Part | `data-part` | Renders                         | Purpose                                     |
| :--- | :---------- | :------------------------------ | :------------------------------------------ |
| Root | `root`      | `<a>` (or the `render` element) | The link: colour, underline, and focus ring |

{/* END: anatomy */}
