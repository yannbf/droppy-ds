# Link

{/* BEGIN: general */}

An inline text link — a link inside a sentence or a short list, not a button and not a nav item.

```tsx
import { Link } from '@droppy/design-system'
```

<Canvas of={LinkStories.Default} />

## Features

- Inherits the surrounding font (`font: inherit`) so it drops into a paragraph, a list, or a
  heading without a size or family mismatch.
- Colored with the primary text token by default; underlines on hover rather than staying
  underlined at rest, so a paragraph of body copy with an inline link doesn't read as noisy.
- No router dependency: renders a plain `<a href>` by default. Pass `render` to swap in a
  router-aware link instead (see below) — the design system itself never imports a router.
- Merges any incoming `className` with its own `droppy-Link` class.

{/* END: general */}

{/* BEGIN: when-to-use */}

## When to use

- A link inside a sentence, a paragraph, or a short inline list of related links.

## When not to use

- A primary or secondary action a visitor is meant to notice and act on — use
  [Button](?path=/docs/actions-button--docs) instead.
- A trail of ancestor pages — use [Breadcrumb](?path=/docs/navigation-breadcrumb--docs).

{/* END: when-to-use */}

## How it works

### Inline in a sentence

`Link` is for a sentence link, not a button or a nav item — it inherits the surrounding text's
font rather than setting its own.

<Canvas of={LinkStories.Inline} />

### Inheriting colour

On a dark surface, `Link` follows `currentColor` from the wrapping context rather than fighting it
with a hard-coded light-mode token.

## Anatomy

`Link` is a single-part component. By default it renders an `<a>`; with `render` it clones the element you pass, so the part is whatever your router link renders.

<Canvas of={LinkStories.Anatomy} />

| Part | `data-part` | Renders                         | Purpose                                     |
| :--- | :---------- | :------------------------------ | :------------------------------------------ |
| Root | `root`      | `<a>` (or the `render` element) | The link: colour, underline, and focus ring |

## Keyboard & screen reader

A real `<a>` (or the router element passed via `render`) — standard link keyboard behaviour
applies, no custom handling.

- **ARIA:** none beyond the native link semantics.
- **Screen reader:** announced as a link with its text content as the accessible name.
- **You must provide:** link text that makes sense out of context (avoid bare "click here").

## Styling

| Token                     | Used for           |
| ------------------------- | ------------------ |
| `--ds-color-text-primary` | Default link color |
| `--ds-shadow-focus`       | Focus ring         |

`className` merges with the component's own `droppy-Link` class. Color is a plain CSS rule, so a
caller can override it with an inline `style`, a `className`, or `currentColor` inheritance.

## API reference

<ArgTypes of={LinkStories} />

### `children`

The link text — keep it descriptive out of context.

<Canvas of={LinkStories.Children} />

### `href`

The destination for the default `<a>`.

<Canvas of={LinkStories.Href} />

### `render`

Swaps the `<a>` for a router-aware link, so the design system itself carries no router dependency.
The passed element owns its own destination, so `href` is dropped rather than spread on top of it
— a present-but-`undefined` key would still clobber a router `Link`'s `to`.

<Canvas of={LinkStories.Render} />

### `className`

Merged onto the root alongside the component's own `droppy-Link` class.
