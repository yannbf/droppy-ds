# Link

{/* BEGIN: anatomy */}

## Anatomy

`Link` is a single-part component. By default it renders an `<a>`; with `render` it clones the element you pass, so the part is whatever your router link renders.

<Canvas of={LinkStories.Anatomy} />

| Part | `data-part` | Renders                         | Purpose                                     |
| :--- | :---------- | :------------------------------ | :------------------------------------------ |
| Root | `root`      | `<a>` (or the `render` element) | The link: colour, underline, and focus ring |

{/* END: anatomy */}

## Do's and don'ts

### Do

- Write link text that names the destination, e.g. "View the menu" rather than "click here":
  screen reader users often browse a list of links out of context
- Pass the app's router element through `render` rather than rebuilding navigation on a plain
  `href`
- Set `rel="noopener noreferrer"` alongside any `target="_blank"`, and say in the link text that a
  new tab opens

### Don't

- Don't nest a control inside a `Link`, or a `Link` inside a control: two controls in one spot
  confuse keyboard focus and screen readers
- Don't rely on colour alone to mark a link inside a paragraph; at rest it matches the surrounding
  body text, so the wording has to make it findable
