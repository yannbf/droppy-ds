# Link

{/* BEGIN: anatomy */}

## Anatomy

`Link` is a single-part component. By default it renders an `<a>`; with `render` it clones the element you pass, so the part is whatever your router link renders.

<Canvas of={LinkStories.Anatomy} />

| Part | `data-part` | Renders                         | Purpose                                     |
| :--- | :---------- | :------------------------------ | :------------------------------------------ |
| Root | `root`      | `<a>` (or the `render` element) | The link: colour, underline, and focus ring |

## API reference

<ArgTypes of={LinkStories} />

### `children`

The link text — keep it descriptive out of context.

<Canvas of={LinkStories.Children} />

### `href`

The destination for the default `<a>`.

<Canvas of={LinkStories.Href} />

### `render`

Swaps the `<a>` for a router-aware link, so the design system itself carries no router dependency.
The passed element owns its own destination, so `href` is dropped rather than spread on top of it
— a present-but-`undefined` key would still clobber a router `Link`'s `to`.

<Canvas of={LinkStories.Render} />

### `className`

Merged onto the root alongside the component's own `droppy-Link` class.
