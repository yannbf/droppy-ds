# Select

## Anatomy

A label above a wrapper that positions the chevron over the native control. There is no listbox part: the options are real `<option>` elements the platform renders.

<Canvas of={SelectStories.Anatomy} />

| Part    | `data-part` | Renders    | Purpose                                |
| :------ | :---------- | :--------- | :------------------------------------- |
| Root    | `root`      | `<div>`    | The field: label above, control below  |
| Label   | `label`     | `<label>`  | Tied to the control by `for`/`id`      |
| Wrapper | `wrapper`   | `<div>`    | Positions the chevron over the control |
| Control | `control`   | `<select>` | The native control                     |

{/* END: anatomy */}
