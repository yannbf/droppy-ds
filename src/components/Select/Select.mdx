# Select

{/* BEGIN: anatomy */}

## Anatomy

A label above a wrapper that positions the chevron over the native control. There is no listbox part: the options are real `<option>` elements the platform renders.

<Canvas of={SelectStories.Anatomy} />

| Part    | `data-part` | Renders    | Purpose                                |
| :------ | :---------- | :--------- | :------------------------------------- |
| Root    | `root`      | `<div>`    | The field: label above, control below  |
| Label   | `label`     | `<label>`  | Tied to the control by `for`/`id`      |
| Wrapper | `wrapper`   | `<div>`    | Positions the chevron over the control |
| Control | `control`   | `<select>` | The native control                     |

{/* END: anatomy */}

## API reference

<ArgTypes of={SelectStories} />

### `label`

The visible label, wired to the control with `for`/`id`.

<Canvas of={SelectStories.Label} />

### `options`

Rendered as both the value and the visible text.

<Canvas of={SelectStories.Options} />

### `value` and `onChange`

The control is fully controlled; `onChange` receives the coerced value.

<Canvas of={SelectStories.Value} />

### `disabled`

Native, and passed straight through — as is every other `<select>` attribute.

<Canvas of={SelectStories.Disabled} />

### `className`

Merged onto the root alongside the component's own `droppy-Select` class.
