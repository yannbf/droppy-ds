# Skeleton

{/* BEGIN: anatomy */}

## Anatomy

`Skeleton` is a single-part component: one `<span>`, so it can sit inline inside a `Heading` or a line of text and take on the surrounding font size. It has no children and announces nothing.

<Canvas of={SkeletonStories.Anatomy} />

| Part | `data-part` | Renders  | Purpose                                                                             |
| :--- | :---------- | :------- | :---------------------------------------------------------------------------------- |
| Root | `root`      | `<span>` | The placeholder: computed width and height, the shimmer gradient, and `aria-hidden` |

{/* END: anatomy */}

## API reference

<ArgTypes of={SkeletonStories} />

### `width`

Numbers are read as pixels; strings pass through unchanged. Defaults to `100%`.

<Canvas of={SkeletonStories.Width} />

### `height`

Numbers are read as pixels; strings pass through unchanged. Defaults to `1em`, so a bare skeleton
matches the text around it.

<Canvas of={SkeletonStories.Height} />

### `className`

Merged onto the root alongside the component's own `droppy-Skeleton` class.

<Canvas of={SkeletonStories.ClassName} />

### `style`

Merged after the computed width and height, so a shape can carry its own border radius or other
overrides on top.

<Canvas of={SkeletonStories.Style} />
