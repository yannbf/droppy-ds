# Skeleton

{/* BEGIN: when-to-use */}

## When to use

- In place of text, an image, or any block of content while it loads, sized to match the shape
  that content will take.
- Composed into an existing layout — a card, a list row, a form — so the page's structure doesn't
  shift once the real content arrives.

## When not to use

- For a full-page loading wait with no layout to preview yet — a shape-matching placeholder needs
  a shape to match.
- For content whose final size isn't known. A skeleton that guesses wrong shifts the layout the
  moment real content replaces it, which is the exact jump skeletons exist to prevent.

{/* END: when-to-use */}
