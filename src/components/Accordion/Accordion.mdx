## Anatomy

`Accordion` renders seven parts, each carrying a `data-part` attribute. Open the story below in
the canvas and use the **Anatomy** panel to hover a part and see it highlighted, or hover the
canvas to activate the matching entry.

<Canvas of={AccordionStories.Anatomy} />

| Part    | `data-part` | Renders    | Purpose                                                                    |
| :------ | :---------- | :--------- | :------------------------------------------------------------------------- |
| Root    | `root`      | `<div>`    | Owns the shared open state, the border, and the column layout              |
| Item    | `item`      | `<div>`    | One collapsible section; carries `[data-panel-open]` while open            |
| Header  | `header`    | `<h3>`     | Puts each trigger in the page outline                                      |
| Trigger | `trigger`   | `<button>` | Toggles its panel; carries `aria-expanded`                                 |
| Icon    | `icon`      | `<svg>`    | The plus glyph, rotated 45° into a cross while open                        |
| Panel   | `panel`     | `<div>`    | The animated region; mounted only while open, sized by the height variable |
| Content | `content`   | `<div>`    | The padded inner wrapper the panel clips as it animates                    |

The tree is flat by design: `items` renders the whole list, so there is no sub-component to
compose. Item order is the array's order.

## Keyboard & screen reader

| Key / interaction | Context         | Action                                                          |
| ----------------- | --------------- | --------------------------------------------------------------- |
| Tab / Shift+Tab   | any             | Moves focus between triggers, in document order                 |
| Enter / Space     | focused trigger | Toggles that item's panel open or closed                        |
| Arrow keys        | any             | No effect — Accordion does not use roving focus between headers |

- **ARIA:** each trigger is a `<button>` with `aria-expanded`, inside an `<h3>` header; each panel
  carries `role="region"` linked to its trigger via `aria-labelledby`.
- **Screen reader:** announces each header as a heading, and each trigger's expanded/collapsed
  state; panel content is announced as a landmark region once open.
- **You must provide:** a meaningful `title` per item — it becomes both the visible label and the
  trigger's accessible name.
