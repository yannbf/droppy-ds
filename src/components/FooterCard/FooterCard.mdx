# FooterCard

{/* BEGIN: when-to-use */}

## When to use

- Inside a page footer, grouping a titled set of links — site navigation, social links, legal
  links.
- Only on a dark footer surface (e.g. `--ds-color-surface-inverse`). FooterCard's text color
  assumes that context and doesn't paint a background of its own — it's a text-on-dark component,
  not a self-contained dark panel.

## When not to use

- A single standalone link — use [Link](?path=/docs/actions-link--docs) directly.
- A trail of ancestor pages — use [Breadcrumb](?path=/docs/navigation-breadcrumb--docs).

{/* END: when-to-use */}

{/* BEGIN: anatomy */}

## Anatomy

A heading above a list of links. The list disappears entirely when `links` is empty, so a column of `children` alone renders no stray `<ul>`.

<Canvas of={FooterCardStories.Anatomy} />

| Part  | `data-part` | Renders                         | Purpose                                            |
| :---- | :---------- | :------------------------------ | :------------------------------------------------- |
| Root  | `root`      | `<div>`                         | The column: heading above, list and children below |
| Title | `title`     | `<h2>`                          | The column heading                                 |
| List  | `list`      | `<ul>`                          | Absent when `links` is empty                       |
| Item  | `item`      | `<li>`                          | One per entry                                      |
| Link  | `link`      | `<a>` (or the `render` element) | Rendered through `Link`                            |
