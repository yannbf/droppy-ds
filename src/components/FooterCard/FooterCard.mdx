# FooterCard

{/* BEGIN: general */}

A titled column of links for a page footer — "Discover us", "Our social media", or any other
grouped set of footer navigation.

```tsx
import { FooterCard } from '@droppy/design-system'
```

<Canvas of={FooterCardStories.Default} />

## Features

- `title` renders as an `<h2>` via `Heading` — a footer typically stacks several `FooterCard`s
  side by side, each its own labeled section.
- `links` is an ordered list of `{ name, href?, external?, render? }`. Each renders through `Link`,
  so it inherits the same `render` escape hatch for router-aware links.
- `external` links get `target="_blank"` and `rel="noopener noreferrer"` automatically.
- `children` renders after the link list (or on its own, when `links` is omitted) — for content
  that isn't a link, like app store badges or a short paragraph.
- FooterCard is designed to live on a dark footer surface, so it owns its own text color —
  `--ds-color-text-on-inverse` on the root, `currentColor` on links — rather than leaving each
  consumer to restate it.
- Merges any incoming `className` with its own `droppy-FooterCard` class.

## How it works

### Text color on dark footers

FooterCard assumes it sits on a dark footer surface and sets its own text color to
`--ds-color-text-on-inverse` accordingly — a consumer doesn't need to override `color` to make it
readable. Links inherit the same color via `currentColor` down an ancestor-qualified chain
(`.droppy-FooterCard .droppy-FooterCard-link`), so a consumer's own CSS reset can't strip it. The
story below renders against `--ds-color-surface-inverse`, the token a footer would actually use.

<Canvas of={FooterCardStories.Default} />

### External links

An item marked `external` opens in a new tab with `rel="noopener noreferrer"` — the escaping
hatch and the security attribute travel together, so a caller can't get one without the other.

<Canvas of={FooterCardStories.ExternalLinks} />

### Router links per item

`render` swaps the default `<a>` for a router-aware link on a single item, the same way
`Breadcrumb` composes its crumbs.

## Anatomy

A heading above a list of links. The list disappears entirely when `links` is empty, so a column of `children` alone renders no stray `<ul>`.

<Canvas of={FooterCardStories.Anatomy} />

| Part  | `data-part` | Renders                         | Purpose                                            |
| :---- | :---------- | :------------------------------ | :------------------------------------------------- |
| Root  | `root`      | `<div>`                         | The column: heading above, list and children below |
| Title | `title`     | `<h2>`                          | The column heading                                 |
| List  | `list`      | `<ul>`                          | Absent when `links` is empty                       |
| Item  | `item`      | `<li>`                          | One per entry                                      |
| Link  | `link`      | `<a>` (or the `render` element) | Rendered through `Link`                            |

{/* END: anatomy */}
