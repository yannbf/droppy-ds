# Spinner

{/* BEGIN: when-to-use */}

## When to use

- An indeterminate wait with no content shape to preview yet — a full page or section load before
  anything is known about what will render.

## When not to use

- A wait where the eventual content's shape is already known — a card, a list row, a form. Use
  [Skeleton](?path=/docs/feedback-status-skeleton--docs) instead, so the layout doesn't jump once the
  real content arrives.

{/* END: when-to-use */}

{/* BEGIN: anatomy */}

## Anatomy

The announcing wrapper, a decorative graphic, and the shapes the keyframes drive. Only the root reaches the accessibility tree.

<Canvas of={SpinnerStories.Anatomy} />

| Part    | `data-part` | Renders        | Purpose                                                  |
| :------ | :---------- | :------------- | :------------------------------------------------------- |
| Root    | `root`      | `<div>`        | The `role="status"` wrapper carrying the accessible name |
| Graphic | `graphic`   | `<svg>`        | The `aria-hidden` drawing surface                        |
| Dot     | `dot`       | `<circle>` × 3 | Same keyframes, staggered by negative `animation-delay`  |
| Arc     | `arc`       | `<path>` × 3   | The sweeping wedges behind the dots                      |

{/* END: anatomy */}
