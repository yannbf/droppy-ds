## API reference

<ArgTypes of={HeadingStories} />

### `children`

The heading text; nodes work as well as strings.

<Canvas of={HeadingStories.Children} />

### `level`

Picks the rendered tag and, on its own, the matching size step — `level={3}` is an `<h3>` at the
level-3 size, not a styled `<div>`.

<Canvas of={HeadingStories.Levels} />

### `size`

Picks the visual step on its own; the tag still follows `level`.

<Canvas of={HeadingStories.Sizes} />

### `className`

Merged onto the root alongside the component's own `droppy-Heading` class.

<Canvas of={HeadingStories.ClassName} />
