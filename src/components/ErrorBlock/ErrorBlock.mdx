## Anatomy

Title, optional illustration, body, and one action — in that DOM order. The heading comes first in the DOM even though the illustration sits above it visually, so the announcement leads with what happened.

<Canvas of={ErrorBlockStories.Anatomy} />

| Part         | `data-part`    | Renders    | Purpose                                                 |
| :----------- | :------------- | :--------- | :------------------------------------------------------ |
| Root         | `root`         | `<div>`    | The centred column holding the whole message            |
| Title        | `title`        | `<h2>`     | What happened                                           |
| Illustration | `illustration` | `<div>`    | The optional slot; absent, nothing renders in its place |
| Body         | `body`         | `<p>`      | The explanation                                         |
| Action       | `action`       | `<button>` | The single recovery action                              |

{/* END: anatomy */}

## API reference

<ArgTypes of={ErrorBlockStories} />

### `title`

The `h2` — say what happened, not just that something did.

<Canvas of={ErrorBlockStories.Title} />

### `body`

The explanation and, ideally, what to try next.

<Canvas of={ErrorBlockStories.Body} />

### `buttonText` and `onButtonClick`

The single recovery action.

<Canvas of={ErrorBlockStories.ButtonText} />

### `illustration`

Optional, and takes any node. The Lottie player and its animation JSON are application assets, so
the slot accepts whatever the caller drives rather than owning an animation itself.

<Canvas of={ErrorBlockStories.Illustration} />

### `className`

Merged onto the root alongside the component's own `droppy-ErrorBlock` class.
