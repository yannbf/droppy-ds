## Anatomy

Title, optional illustration, body, and one action — in that DOM order. The heading comes first in the DOM even though the illustration sits above it visually, so the announcement leads with what happened.

<Canvas of={ErrorBlockStories.Anatomy} />

| Part         | `data-part`    | Renders    | Purpose                                                 |
| :----------- | :------------- | :--------- | :------------------------------------------------------ |
| Root         | `root`         | `<div>`    | The centred column holding the whole message            |
| Title        | `title`        | `<h2>`     | What happened                                           |
| Illustration | `illustration` | `<div>`    | The optional slot; absent, nothing renders in its place |
| Body         | `body`         | `<p>`      | The explanation                                         |
| Action       | `action`       | `<button>` | The single recovery action                              |
