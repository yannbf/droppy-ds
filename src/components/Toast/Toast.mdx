| Description | `description` | `<div>`    | The supporting line                                 |
| Close       | `close`       | `<button>` | `aria-hidden` until the stack is hovered or focused |

## API reference

<ArgTypes of={ToastStories} />

### `children`

The tree that raises toasts; the provider renders it as-is.

<Canvas of={ToastStories.Children} />

### `timeout`

Milliseconds before a toast auto-dismisses. `0` keeps it until dismissed.

<Canvas of={ToastStories.Timeout} />

### `limit`

How many show at once. Older toasts are marked limited rather than dropped.

<Canvas of={ToastStories.Limit} />

### `container`

Where to portal the stack — an element or a selector.

<Canvas of={ToastStories.Container} />

### `className`

Merged onto the viewport alongside the component's own `droppy-Toast` class.

<Canvas of={ToastStories.ClassName} />
