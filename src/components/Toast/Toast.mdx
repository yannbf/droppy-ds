## Keyboard & screen reader

| Key / interaction          | Context            | Action                                         |
| -------------------------- | ------------------ | ---------------------------------------------- |
| F6                         | anywhere           | Jumps focus to the toast stack                 |
| Tab (from the stack)       | open               | Enters the stack at the newest toast           |
| Escape                     | a toast is focused | Closes that toast; focus moves to the next one |
| Shift+Tab (from the stack) | open               | Returns focus to wherever it was before        |

- **ARIA:** the viewport is a live region so a new toast is announced without moving focus; each toast is announced according to its priority.
- **Screen reader:** hears the toast's title and description as it appears, and can reach its `Dismiss` button by tabbing into the stack.
- **You must provide:** a `title` or `description` on every toast that carries the information the reader needs — the toast itself supplies no default text.
