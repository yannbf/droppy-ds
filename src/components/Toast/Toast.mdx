A stack of transient, self-dismissing notifications for things the reader doesn't need to act on right away.

```tsx
import { ToastProvider, useToast } from '@droppy/design-system'
```

<Canvas of={ToastStories.Default} />

## Features

- **No markup to write per toast.** `ToastProvider` renders the viewport and the toast list for you — call `useToast().add(...)` from anywhere beneath it and a toast appears.
- **Auto-dismisses on a timer**, and stacks newest-first when more than one is visible at once.
- **Announced to screen readers** through the viewport's live region, without stealing focus on open.
- **Portals to `document.body`** by default, so a parent's `overflow: hidden` or stacking context can't clip it. `container` retargets the portal, matching [Modal](?path=/docs/overlays-modal--docs)'s prop of the same name.

## How it works

### The close affordance

The close button is `aria-hidden` until the stack is hovered or focused, so a single passing
notification doesn't compete with the page for keyboard attention.

<Canvas of={ToastStories.CloseAppearsOnHover} />

### Enter and exit motion

Each toast enters and leaves off `[data-starting-style]` and `[data-ending-style]`, and the exit
additionally reads `[data-swipe-direction]` so a swiped toast leaves the way it was pushed rather
than fading in place.

## Anatomy

A portalled viewport holding one node per queued toast. There is no trigger part — a toast is raised imperatively through `useToast().add(...)`, so nothing here is composed by hand. The anatomy story portals into a node inside the story canvas via `container`, so the **Anatomy** panel can reach the parts — it only scans the canvas, and the default portal target is the document body.

<Canvas of={ToastStories.Anatomy} />

| Part        | `data-part`   | Renders    | Purpose                                             |
| :---------- | :------------ | :--------- | :-------------------------------------------------- |
| Viewport    | `root`        | `<div>`    | The stack region the toasts portal into             |
| Toast       | `toast`       | `<div>`    | One notification; owns the enter/exit states        |
| Content     | `content`     | `<div>`    | Lays the text out against the close button          |
| Title       | `title`       | `<div>`    | The headline                                        |
| Description | `description` | `<div>`    | The supporting line                                 |
| Close       | `close`       | `<button>` | `aria-hidden` until the stack is hovered or focused |

{/* END: anatomy */}
