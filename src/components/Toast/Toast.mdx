# Toast

{/* BEGIN: when-to-use */}

## When to use

- A confirmation of something that already happened — a draft saved, a file archived, an export finished — that the reader doesn't need to dismiss to keep working.
- A transient status message like "Copied," which [Tooltip](?path=/docs/overlays-tooltip--docs) explicitly can't provide, since a tooltip's content is never announced to screen readers.

## When not to use

- A decision the reader must make before continuing — use [Modal](?path=/docs/overlays-modal--docs) instead, which blocks the page and traps focus until it's answered.
- Content the reader must be able to reach at their own pace rather than within a timeout — put it on the page instead.

{/* END: when-to-use */}

{/* BEGIN: anatomy */}

## Anatomy

A portalled viewport holding one node per queued toast. There is no trigger part — a toast is raised imperatively through `useToast().add(...)`, so nothing here is composed by hand. The anatomy story portals into a node inside the story canvas via `container`, so the **Anatomy** panel can reach the parts — it only scans the canvas, and the default portal target is the document body.

<Canvas of={ToastStories.Anatomy} />

| Part        | `data-part`   | Renders    | Purpose                                             |
| :---------- | :------------ | :--------- | :-------------------------------------------------- |
| Viewport    | `root`        | `<div>`    | The stack region the toasts portal into             |
| Toast       | `toast`       | `<div>`    | One notification; owns the enter/exit states        |
| Content     | `content`     | `<div>`    | Lays the text out against the close button          |
| Title       | `title`       | `<div>`    | The headline                                        |
| Description | `description` | `<div>`    | The supporting line                                 |
| Close       | `close`       | `<button>` | `aria-hidden` until the stack is hovered or focused |

## Related

- For a decision that must block the page until it's answered, use [Modal](?path=/docs/overlays-modal--docs).
- For a hint about a control before it's activated — never for a confirmation message — use [Tooltip](?path=/docs/overlays-tooltip--docs).
