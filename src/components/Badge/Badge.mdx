## Anatomy

`Badge` is a single-part component: one `<span>` with the label as its only child. There are no slots, so anything around it — placement, spacing, a photo behind it — belongs to the call site.

<Canvas of={BadgeStories.Anatomy} />

| Part | `data-part` | Renders  | Purpose                                                            |
| :--- | :---------- | :------- | :----------------------------------------------------------------- |
| Root | `root`      | `<span>` | The pill: background, radius, padding, and the capitalization rule |

## Decision log

- **2026-07**: Badge absorbed RestaurantCard's hand-rolled NewTag styled-span as `<Badge text="new" variant="positive" />`, collapsing Mealdrop's two implementations of one visual role and establishing the `variant` API for semantic colour roles while keeping the original text-as-prop API; absolute positioning over the card photo was judged a call-site concern and stays in the app ([Mealdrop parity doc](https://github.com/yannbf/droppy-ds/blob/main/docs/MEALDROP-PARITY.md), [migration commit](https://github.com/yannbf/mealdrop/commit/dea29009cb06ec78eb7e2c52f216da78d913e747)).
- **2026-07**: casing moved into CSS per the [brand guidelines](?path=/docs/brand-guidelines--docs) rule "sentence case everywhere — never Title Case, never ALL CAPS": badge labels are written lowercase in source and `text-transform: capitalize` handles presentation, so labels are never uppercased by hand.
- **2026-08**: `--ds-color-badge-positive-text` was pinned to the ink value (`ds.palette.neutral.900`) in both themes instead of following the theme-flipping `text.primary` role — the soft green "good news" accent is a fixed surface in both themes, and per the [brand guidelines](?path=/docs/brand-guidelines--docs) "Accents are surfaces, not ink", so text on it stays ink rather than inverting with the theme ([droppy-ds #292](https://github.com/yannbf/droppy-ds/pull/292), closing [#28](https://github.com/yannbf/droppy-ds/issues/28)).
- **Built on a plain `<span>` element.** Droppy supplies the props, the theme classes, and the copy around it.

## Known issues & open questions

- [#29](https://github.com/yannbf/droppy-ds/issues/29): docs promise casing-normalized rendering, but CSS `capitalize` never lowercases — "VEGAN" renders as-is, against the brand's "never ALL CAPS" sentence-case rule. **Workaround:** lowercase the label at the call site (`text={label.toLowerCase()}`), and query the raw string in tests.
- [#31](https://github.com/yannbf/droppy-ds/issues/31): JSX children are silently discarded at runtime; empty or missing `text` renders a visible empty pill. **Workaround:** always use the `text` prop and guard falsy labels at the call site (`{tag ? <Badge text={tag}/> : null}`); typecheck JSX in JS projects.
- [#34](https://github.com/yannbf/droppy-ds/issues/34): no wrap/overflow strategy — multi-word labels wrap into cramped line-height:1 lines; unbroken strings overflow the container. **Workaround:** add `white-space: nowrap` via className/app CSS and handle oversized labels at the call site.
- [#37](https://github.com/yannbf/droppy-ds/issues/37): `dangerouslySetInnerHTML` is accepted by the types but always crashes on render. **Workaround:** never pass `dangerouslySetInnerHTML`; render markup around the badge instead.
- [#41](https://github.com/yannbf/droppy-ds/issues/41): positive variant's bold is synthesized — the [brand guidelines](?path=/docs/brand-guidelines--docs) ship Hind at weights 400/500 only, so there is no real 700 face and the bold disappears under `font-synthesis: none`. **Workaround:** declare a real Hind 700 @font-face in app CSS (merges into the family), or avoid `font-synthesis: none` on badge text.
- [#43](https://github.com/yannbf/droppy-ds/issues/43): excluded from the theme cross-fade — colors snap on theme toggle while theme-layer parts fade over 250ms. **Workaround:** add a matching background-color/color transition on `.droppy-Badge` in app CSS.
- [#122](https://github.com/yannbf/droppy-ds/issues/122): components are plain function components, so `ref` type-checks but never attaches on React 18 (works on React 19 only).
- [#129](https://github.com/yannbf/droppy-ds/issues/129): focus indicators are box-shadow-only with `outline: none`, so they vanish entirely in Windows High Contrast mode.
- [#286](https://github.com/yannbf/droppy-ds/issues/286): the docs describe Badge as "a small pill", but it renders with `--ds-radius-control` (4px) — on the radius scale documented in the [Spacing and layout tokens](?path=/docs/design-tokens-spacing-and-layout--docs), pills sit on the 32px `--ds-radius-pill` rung, so the copy and the radius disagree about which shape Badge is.
