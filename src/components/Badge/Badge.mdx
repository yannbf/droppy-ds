## Brand

`variant="positive"` carries the [brand guidelines'](?path=/docs/brand-guidelines--docs) soft
green "good news" accent, used for "new" tags among other positive moments. Per the guidelines,
"Accents are surfaces, not ink" — soft green is a background that carries dark text, so the
badge's text stays pinned to the ink color (`Ink/primary text: #2C2C2C`) in both light and dark
theme rather than following the page's theme-flipping text color.
