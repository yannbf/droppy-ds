## Anatomy

`Badge` is a single-part component: one `<span>` with the label as its only child. There are no slots, so anything around it — placement, spacing, a photo behind it — belongs to the call site.

<Canvas of={BadgeStories.Anatomy} />

| Part | `data-part` | Renders  | Purpose                                                            |
| :--- | :---------- | :------- | :----------------------------------------------------------------- |
| Root | `root`      | `<span>` | The pill: background, radius, padding, and the capitalization rule |

## API reference

<ArgTypes of={BadgeStories} />

### `text`

The label, and the only content the badge renders. Capitalization is a CSS rule, so the DOM keeps
whatever casing you passed.

<Canvas of={BadgeStories.Text} />

### `variant`

The neutral default matches Mealdrop's original badge; `positive` matches its hand-rolled "new"
tag look, minus the absolute positioning that was specific to a restaurant card's photo —
placement is now the call site's job. The variant changes background, text color, and weight;
padding, radius, and size stay put.

<Canvas of={BadgeStories.Variant} />

### `className`

Merged onto the root alongside the component's own `droppy-Badge` class.
