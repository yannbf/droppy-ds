# Badge

{/* BEGIN: general */}

A small pill for a short, static label — a dietary tag, a category, a "new" flag.

```tsx
import { Badge } from '@droppy/design-system'
```

<Canvas of={BadgeStories.Default} />

## Features

- `text` renders capitalized regardless of the casing passed in — `"vegan"` and `"Vegan"` render
  identically.
- `variant="positive"` swaps the background, text color, and font weight for an affirmative flag
  such as "new" — padding, radius, and size stay the same as the neutral default.
- Merges any incoming `className` with its own `droppy-Badge` class.
