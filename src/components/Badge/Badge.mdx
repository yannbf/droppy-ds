## Keyboard & screen reader

`Badge` renders a non-interactive `<span>` — there is no keyboard interaction to document.

- **ARIA:** none — a plain text node, read as part of the surrounding content.
- **Screen reader:** announced as part of the enclosing text flow, in reading order.
- **You must provide:** an accessible name on whatever control the badge sits inside, if any —
  `Badge` itself carries none.
