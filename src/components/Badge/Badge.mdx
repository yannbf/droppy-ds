# Badge

{/* BEGIN: when-to-use */}

## When to use

- A short, static label attached to something else — a dietary tag on a menu item, a category
  chip, a "new" flag on a card.
- Anywhere the surrounding layout, not the badge itself, decides placement — `Badge` renders
  inline where you put it; floating it over a photo or corner is a call-site concern.

## When not to use

- For a live status that changes over time (loading, saved, failed) — that's status text, not a
  label. Style it with the theme's text tokens directly rather than stretching `Badge`'s two
  variants to cover states it wasn't designed for.
- As a clickable control — `Badge` has no interactive semantics. If the label needs to respond to
  a click, use [Button](?path=/docs/actions-button--docs) with `clear` instead.

{/* END: when-to-use */}

{/* BEGIN: anatomy */}

## Anatomy

`Badge` is a single-part component: one `<span>` with the label as its only child. There are no slots, so anything around it — placement, spacing, a photo behind it — belongs to the call site.

| :--- | :---------- | :------- | :----------------------------------------------------------------- |
| Root | `root`      | `<span>` | The pill: background, radius, padding, and the capitalization rule |
