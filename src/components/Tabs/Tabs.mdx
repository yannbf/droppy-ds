{/* BEGIN: general */}

A set of panels, one visible at a time, switched by a row of tab buttons — settings sections, a
profile's sub-views, anything reviewed one part at a time rather than all at once.

```tsx
import { Tabs } from '@droppy/design-system'
```

<Canvas of={TabsStories.Default} />

## Features

- **`tabs` covers the common case**: an array of `{ value, label, content, disabled? }` renders
  the whole tablist and its panels — no need to compose `Tabs.Tab`/`Panel` by hand.
- **Renders the theme's `Indicator`**, an animated highlight that slides beneath the active tab.
- **`value`/`defaultValue`/`onValueChange` passthrough**, for a controlled set of tabs driven by
  state outside the component.
- **Activates on click**, not on focus alone — arrow-keying through the tabs moves focus without
  changing which panel is shown, matching
  [WCAG 2.5.2 Pointer Cancellation](https://www.w3.org/WAI/WCAG21/Understanding/pointer-cancellation.html).

{/* END: general */}

## How it works

### Focus does not activate

Tabs activate on click, not on focus: arrowing along the row moves focus without swapping the
panel, so a keyboard user can read the labels before committing. Only Enter, Space, or a click
activates.

<Canvas of={TabsStories.FocusDoesNotActivate} />

### Controlled value

`value` with `onValueChange` hands the active tab to the caller's state. One without the other
leaves the row stuck — the callback fires, the tab never moves.

<Canvas of={TabsStories.ControlledValue} />

### The sliding indicator

`Tabs.Indicator` writes the active tab's measured position and size to CSS custom properties,
which the theme transitions on top of.

## Anatomy

A tab row with its indicator, and one panel per tab. The list is flat — `tabs` renders the whole set, so there is no `Tabs.Tab`/`Tabs.Panel` to compose by hand.

<Canvas of={TabsStories.Anatomy} />

| Part      | `data-part` | Renders    | Purpose                                                                  |
| :-------- | :---------- | :--------- | :----------------------------------------------------------------------- |
| Root      | `root`      | `<div>`    | Owns the active value and links tabs to panels                           |
| List      | `list`      | `<div>`    | The `role="tablist"` row                                                 |
| Tab       | `tab`       | `<button>` | One per entry, carrying `aria-selected`                                  |
| Indicator | `indicator` | `<span>`   | The sliding underline; writes the active tab's position as CSS variables |
| Viewport  | `viewport`  | `<div>`    | Wraps the panels                                                         |
| Panel     | `panel`     | `<div>`    | One per tab; only the active one shows                                   |

{/* END: anatomy */}
