## API reference

<ArgTypes of={ButtonStories} />

### `children`

The label. Omitted, the button is icon-only and needs an `aria-label`.

<Canvas of={ButtonStories.Children} />

### `clear`

Strips the fill, for the secondary action beside a primary one.

<Canvas of={ButtonStories.Clear} />

### `large`

Adds height, for the one action a screen is really about.

<Canvas of={ButtonStories.Large} />

### `round`

Fully rounds the control — pair it with an icon and no label.

<Canvas of={ButtonStories.Round} />

### `icon`

Renders a glyph before the label, spaced with `gap` rather than a spacer element — one fewer DOM
node than Mealdrop's original, for the same 1rem.

<Canvas of={ButtonStories.IconProp} />

### `iconSize`

Overrides the glyph size without touching the button's own padding.

<Canvas of={ButtonStories.IconSize} />

### `disabled`

Dims the control and stops it firing `onClick`.

<Canvas of={ButtonStories.Disabled} />

### `className`

Merged onto the root alongside the component's own `droppy-Button` class.

<Canvas of={ButtonStories.ClassName} />
