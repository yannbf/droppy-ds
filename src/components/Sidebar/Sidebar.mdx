A panel that slides in from the trailing edge, for content reviewed alongside the page rather than instead of it.

## Features

- **Focus trap** — Tab loops inside the panel while it's open, so keyboard users can't tab into the page behind it.
- **Scroll lock** — the page behind the sidebar stops scrolling while it's open.
- **Escape, outside-press, and swipe-to-dismiss** — closing works from the keyboard, a click outside the panel, or a swipe toward the trailing edge on touch.
- **Full-width on mobile** — below 768px the panel takes the full viewport width instead of a fixed 420px.
- **Pinned footer slot** — an optional `footer` sits fixed to the bottom of the panel while the content above it scrolls independently.
- **Portal by default** — content renders at the end of `document.body`, so a parent's `overflow: hidden` or `z-index` stacking context can't clip or bury it.
- **ARIA dialog wiring** — `role="dialog"` and the accessible name (from `title`) are set for you.

## How it works

### The pinned footer

The footer stays put and the content scrolls above it, so a long order never pushes the checkout
button out of reach.

<Canvas of={SidebarStories.PinnedFooterWithScrollingContent} />

### Responsive width

Below the mobile breakpoint the panel takes the full width.

<Canvas of={SidebarStories.FullWidthOnMobile} />

### Slide motion

The panel slides from the trailing edge off `[data-starting-style]` and `[data-ending-style]`, and
stays mounted through the exit so the close animation runs before it leaves. Base UI drives
swipe-to-dismiss from the same states.

## Anatomy

A backdrop and the sliding panel, split into a top bar, a scrolling content region, and an optional pinned footer. The anatomy story portals into a node inside the story canvas via `container`, so the **Anatomy** panel can reach the parts — it only scans the canvas, and the default portal target is the document body.

<Canvas of={SidebarStories.Anatomy} />

| Part     | `data-part` | Renders    | Purpose                                     |
| :------- | :---------- | :--------- | :------------------------------------------ |
| Backdrop | `backdrop`  | `<div>`    | The dimmed layer behind the panel           |
| Popup    | `root`      | `<div>`    | The sliding panel: focus trap, swipe, shape |
| Top bar  | `topbar`    | `<div>`    | Holds the title and the close button        |
| Title    | `title`     | `<h4>`     | The heading; also names the dialog          |
| Close    | `close`     | `<button>` | The round icon button that dismisses        |
| Content  | `content`   | `<div>`    | The scrolling region between the two        |
| Footer   | `footer`    | `<div>`    | Pinned to the bottom; absent without one    |
