# Sidebar

## Anatomy

A backdrop and the sliding panel, split into a top bar, a scrolling content region, and an optional pinned footer. The anatomy story portals into a node inside the story canvas via `container`, so the **Anatomy** panel can reach the parts — it only scans the canvas, and the default portal target is the document body.

<Canvas of={SidebarStories.Anatomy} />

| Part     | `data-part` | Renders    | Purpose                                     |
| :------- | :---------- | :--------- | :------------------------------------------ |
| Backdrop | `backdrop`  | `<div>`    | The dimmed layer behind the panel           |
| Popup    | `root`      | `<div>`    | The sliding panel: focus trap, swipe, shape |
| Top bar  | `topbar`    | `<div>`    | Holds the title and the close button        |
| Title    | `title`     | `<h4>`     | The heading; also names the dialog          |
| Close    | `close`     | `<button>` | The round icon button that dismisses        |
| Content  | `content`   | `<div>`    | The scrolling region between the two        |
| Footer   | `footer`    | `<div>`    | Pinned to the bottom; absent without one    |

{/* END: anatomy */}
