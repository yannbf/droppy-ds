## Keyboard & screen reader

| Key                 | Action                                                                                                      |
| ------------------- | ----------------------------------------------------------------------------------------------------------- |
| `Tab` / `Shift+Tab` | Moves focus through the panel's tabbable elements; loops back to the start rather than escaping to the page |
| `Escape`            | Closes the panel                                                                                            |

- **ARIA**: the popup carries `role="dialog"`; the accessible name is wired automatically from the `title` prop.
- **Screen reader**: on open, the dialog is announced by its title; on close, focus returns to wherever it was before the panel opened.
- **Gesture honesty**: swipe-to-dismiss is pointer-only and has no keyboard equivalent — keyboard and screen reader users rely on Escape and the visible close button, both always present regardless of touch support.
- **You must provide:** a `title` that actually describes the panel's contents ("Your order" rather than something generic) — it is the only accessible name the dialog gets.
