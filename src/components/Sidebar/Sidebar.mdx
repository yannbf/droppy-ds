# Sidebar

{/* BEGIN: when-to-use */}

## When to use

- Content the person reviews _alongside_ the page rather than instead of it — a cart is the shape the `Open` story demonstrates: line items stay visible while the page underneath is still there to return to.
- A running total or a set of filters the person may check, adjust, and dismiss without the flow being interrupted by a forced decision.
- Content that benefits from a pinned action at the bottom while the rest scrolls — the `WithFooter` story's total-and-checkout pattern.

## When not to use

- To ask for a single decision that should block the rest of the page until it's made — a confirmation, an "are you sure" — use [Modal](?path=/docs/overlays-modal--docs). Sidebar shares the page; Modal takes it over.
- To explain what a control does before it's activated, use [Tooltip](?path=/docs/overlays-tooltip--docs) — a hint doesn't need a panel or a focus trap.

{/* END: when-to-use */}

{/* BEGIN: anatomy */}

## Anatomy

A backdrop and the sliding panel, split into a top bar, a scrolling content region, and an optional pinned footer. The anatomy story portals into a node inside the story canvas via `container`, so the **Anatomy** panel can reach the parts — it only scans the canvas, and the default portal target is the document body.

<Canvas of={SidebarStories.Anatomy} />

| Part     | `data-part` | Renders    | Purpose                                     |
| :------- | :---------- | :--------- | :------------------------------------------ |
| Backdrop | `backdrop`  | `<div>`    | The dimmed layer behind the panel           |
| Popup    | `root`      | `<div>`    | The sliding panel: focus trap, swipe, shape |
| Top bar  | `topbar`    | `<div>`    | Holds the title and the close button        |
| Title    | `title`     | `<h4>`     | The heading; also names the dialog          |
| Close    | `close`     | `<button>` | The round icon button that dismisses        |
| Content  | `content`   | `<div>`    | The scrolling region between the two        |
| Footer   | `footer`    | `<div>`    | Pinned to the bottom; absent without one    |
