# Body

{/* BEGIN: when-to-use */}

## When to use

- Paragraph copy, helper text, and captions that carry no heading semantics of their own.
- A form label or figure caption, chosen via `type`, that should still share the body type scale.

## When not to use

- A page or section title that belongs in the document outline — use
  [Heading](?path=/docs/typography-heading--docs) instead, so it's announced as a heading and
  reachable via a screen reader's heading-navigation tools.

{/* END: when-to-use */}
