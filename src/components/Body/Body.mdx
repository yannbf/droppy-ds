## Keyboard & screen reader

`Body` renders a static, non-interactive element — there's no keyboard interaction to document.

- **ARIA:** none added. The rendered tag is whichever native element `type` selects, unchanged.
- **Screen reader:** read as ordinary text. A `type="label"` renders a real `<label>`, but `Body`
  doesn't wire its association to a control — pair it with a matching `htmlFor`/`id` yourself, the
  same as any bare `<label>`.
- **You must provide:** the `htmlFor`/`id` pairing if you use `type="label"` to label a control —
  `Body` forwards the prop but doesn't generate or match an id for you.
