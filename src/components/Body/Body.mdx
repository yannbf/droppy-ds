## API reference

<ArgTypes of={BodyStories} />

### `children`

The text, or any nodes to render inside it.

<Canvas of={BodyStories.Children} />

### `size`

Optional — unset renders the base body size (`--ds-type-size-md`). `S`, `XS`, and `XXS` step down
from there.

<Canvas of={BodyStories.Sizes} />

### `fontWeight`

Independent of both `size` and `type`.

<Canvas of={BodyStories.Weights} />

### `type`

Picks the rendered element. All four share the same styling.

<Canvas of={BodyStories.ElementChoice} />

### `color`

Sets the text color inline, ahead of the theme's token.

<Canvas of={BodyStories.ColorOverride} />

### `className`

Merged onto the root alongside the component's own `droppy-Body` class.

<Canvas of={BodyStories.ClassName} />
