# ScrollArea

{/* BEGIN: anatomy */}

## Anatomy

A clipped root, the scrolling viewport and its content wrapper, then a scrollbar with a thumb per axis. Sizing is fixed by the theme layer — `className` is the escape hatch for one-off layout changes.

<Canvas of={ScrollAreaStories.Anatomy} />

| Part      | `data-part` | Renders | Purpose                                               |
| :-------- | :---------- | :------ | :---------------------------------------------------- |
| Root      | `root`      | `<div>` | The clipped box                                       |
| Viewport  | `viewport`  | `<div>` | The scrolling window                                  |
| Content   | `content`   | `<div>` | The wrapper the viewport scrolls                      |
| Scrollbar | `scrollbar` | `<div>` | One per axis; mounted only once the content overflows |
| Thumb     | `thumb`     | `<div>` | The draggable handle                                  |
| Corner    | `corner`    | `<div>` | Only with `orientation="both"`                        |

{/* END: anatomy */}

## API reference
