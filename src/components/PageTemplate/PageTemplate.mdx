# PageTemplate

{/* BEGIN: when-to-use */}

## When to use

- As the outermost layout of a routed page, wrapping the app's own header and footer components
  around whatever page content renders for that route.

## When not to use

- For a section within a page — use [Container](?path=/docs/layout-structure-container--docs) or
  [PageSection](?path=/docs/layout-structure-pagesection--docs) instead.

{/* END: when-to-use */}

{/* BEGIN: anatomy */}

## Anatomy

A column of header, content, and footer. Only the content area is a part the template owns — header and footer are whatever nodes the caller passes, rendered as-is outside the landmark.

<Canvas of={PageTemplateStories.Anatomy} />

| Part    | `data-part` | Renders  | Purpose                                                         |
| :------ | :---------- | :------- | :-------------------------------------------------------------- |
| Root    | `root`      | `<div>`  | The column: header, content, footer in order                    |
| Content | `content`   | `<main>` | The landmark, carrying the min-height that pins the footer down |

{/* END: anatomy */}
