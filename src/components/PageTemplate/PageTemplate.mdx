# PageTemplate

{/* BEGIN: general */}

The page shell: header, a `<main>` content area, and footer — the top-level layout every routed
page sits inside.

```tsx
import { PageTemplate } from '@droppy/design-system'
```

<Canvas of={PageTemplateStories.Default} />

## Features

- `header` and `footer` are optional slots rendered outside the `<main>` landmark, above and below
  the content area respectively.
- `children` renders inside `<main>` — the one content landmark per page, so assistive tech can
  jump straight to it.
- The content area carries `min-height: calc(100vh - 200px)`, a literal allowance for a typical
  header + footer height, so a short page's footer still lands at the bottom of the viewport
  instead of riding up under the fold.
- Merges any incoming `className` with its own `droppy-PageTemplate` class.

## Anatomy

A column of header, content, and footer. Only the content area is a part the template owns — header and footer are whatever nodes the caller passes, rendered as-is outside the landmark.

<Canvas of={PageTemplateStories.Anatomy} />

| Part    | `data-part` | Renders  | Purpose                                                         |
| :------ | :---------- | :------- | :-------------------------------------------------------------- |
| Root    | `root`      | `<div>`  | The column: header, content, footer in order                    |
| Content | `content`   | `<main>` | The landmark, carrying the min-height that pins the footer down |
