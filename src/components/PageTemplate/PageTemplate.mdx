# PageTemplate

{/* BEGIN: when-to-use */}

## When to use

- As the outermost layout of a routed page, wrapping the app's own header and footer components
  around whatever page content renders for that route.

## When not to use

- For a section within a page — use [Container](?path=/docs/layout-structure-container--docs) or
  [PageSection](?path=/docs/layout-structure-pagesection--docs) instead.

{/* END: when-to-use */}
