## API reference

<ArgTypes of={IconButtonStories} />

### `name`

Picks the glyph. The button is icon-only, so pass `aria-label` alongside it.

<Canvas of={IconButtonStories.Name} />

### `small`

Swaps the 4rem control for the 3rem one, glyph included.

<Canvas of={IconButtonStories.Small} />

### `className`

Merged onto the root alongside the component's own `droppy-IconButton` class.
