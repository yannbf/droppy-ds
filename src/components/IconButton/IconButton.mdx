# IconButton

{/* BEGIN: anatomy */}

## Anatomy

The circular control and the glyph it centres. There is no label part — the button is icon-only, so its accessible name comes from `aria-label`.

<Canvas of={IconButtonStories.Anatomy} />

| Part | `data-part` | Renders    | Purpose                                                             |
| :--- | :---------- | :--------- | :------------------------------------------------------------------ |
| Root | `root`      | `<button>` | The circle: fixed size, radius, and focus ring                      |
| Icon | `icon`      | `<svg>`    | The glyph, sized by `small` and coloured independently of the theme |

{/* END: anatomy */}

## API reference

<ArgTypes of={IconButtonStories} />

### `name`

Picks the glyph. The button is icon-only, so pass `aria-label` alongside it.

<Canvas of={IconButtonStories.Name} />

### `small`

Swaps the 4rem control for the 3rem one, glyph included.

<Canvas of={IconButtonStories.Small} />

### `className`

Merged onto the root alongside the component's own `droppy-IconButton` class.
