## Keyboard & screen reader

Icon renders a non-interactive `<svg>` — there is no keyboard interaction to document.

- **ARIA**: `aria-hidden="true"` and `focusable="false"` on the root element, always.
- **Screen reader**: not announced — the icon contributes nothing to the accessibility tree.
- **You must provide:** the accessible name on whatever control renders the icon (`aria-label` or
  visible text) — `Icon` itself carries none.
