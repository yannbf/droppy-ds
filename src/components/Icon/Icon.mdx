# Icon

## Anatomy

`Icon` is a single-part component: one `<svg>`, whose paths come from the bundled set that `name` indexes into. Nothing inside it is addressable.

<Canvas of={IconStories.Anatomy} />

| Part | `data-part` | Renders | Purpose                                                               |
| :--- | :---------- | :------ | :-------------------------------------------------------------------- |
| Root | `root`      | `<svg>` | The glyph: viewBox, stroke colour, and the width/height/minWidth trio |

{/* END: anatomy */}

## API reference

<ArgTypes of={IconStories} />

### `name`

Indexes into the bundled set — every icon in it, below.

<Canvas of={IconStories.Name} />

### `size`

Takes any CSS length or a number of pixels, and drives width, height, and `minWidth` together, so
the icon holds its size even inside a shrinking flex row.

<Canvas of={IconStories.Size} />

### `color`

Sets the stroke inline, ahead of the theme's icon token.

<Canvas of={IconStories.Color} />

### `className`

Merged onto the root alongside the component's own `droppy-Icon` class.

<Canvas of={IconStories.ClassName} />
