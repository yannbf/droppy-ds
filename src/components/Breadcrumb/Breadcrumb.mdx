# Breadcrumb

{/* BEGIN: anatomy */}

## Anatomy

A labelled landmark around an ordered list, one item per crumb. A crumb renders as a link when it has a destination and as text when it does not — usually the last one.

<Canvas of={BreadcrumbStories.Anatomy} />

| Part      | `data-part` | Renders  | Purpose                                    |
| :-------- | :---------- | :------- | :----------------------------------------- |
| Root      | `root`      | `<nav>`  | The `aria-label="breadcrumb"` landmark     |
| List      | `list`      | `<ol>`   | Crumb order is document order              |
| Item      | `item`      | `<li>`   | Holds one crumb and its trailing separator |
| Link      | `link`      | `<a>`    | A crumb with a destination                 |
| Text      | `text`      | `<span>` | A crumb without one                        |
| Separator | `separator` | `<span>` | The `aria-hidden` slash; never announced   |

{/* END: anatomy */}

## API reference

<ArgTypes of={BreadcrumbStories} />

### `items`

The trail, as `{ label, href?, render? }`. The last item is the current page.

<Canvas of={BreadcrumbStories.Items} />

A single crumb is the current page on its own, and no separator renders.

<Canvas of={BreadcrumbStories.SingleCrumb} />

### Item `render`

Cloned with the crumb's link class and, on the last item, `aria-current`. The passed element owns
its own destination, so `href` is dropped rather than spread on top of it.

<Canvas of={BreadcrumbStories.ItemRender} />

### `className`

Merged onto the root alongside the component's own `droppy-Breadcrumb` class.

<Canvas of={BreadcrumbStories.ClassName} />
