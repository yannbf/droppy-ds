## Anatomy

Two parts, and only the trigger is reachable by the **Anatomy** panel: the popup is portalled to the document body, outside the canvas the panel scans, and `Tooltip` exposes no `container` prop the way `Modal` and `Sidebar` do. The popup still carries its `data-part` for anyone inspecting the DOM. Note the trigger is the child element itself — `Tooltip` renders no wrapper around it, so the layout stays flat.

<Canvas of={TooltipStories.Anatomy} />

| Part    | `data-part` | Renders           | Purpose                                     |
| :------ | :---------- | :---------------- | :------------------------------------------ |
| Trigger | `trigger`   | the child element | Rendered as the trigger itself, not wrapped |
| Popup   | `popup`     | `<div>`           | The tip; portalled outside the canvas       |
