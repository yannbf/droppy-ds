# PageSection

{/* BEGIN: general */}

A titled content section — a heading with an optional "view all" action above whatever the
caller composes below it, like a home page's Categories or Restaurants row.

```tsx
import { PageSection } from '@droppy/design-system'
```

[Button](?path=/docs/actions-button--docs).

<Canvas of={PageSectionStories.Default} />

## Features

- Renders `title` as a level-2 [Heading](?path=/docs/typography-heading--docs), with an optional
  `Button` beside it when `topButtonLabel` is set.
- `onTopButtonClick` fires from that button; the button is a `clear` variant, so it reads as a
  secondary action next to the heading rather than competing with it.
- Caps width at 1600px and centers from the 1024px breakpoint up, matching
  [Container](?path=/docs/layout-structure-container--docs)'s desktop bound; below that it fills its
  parent with its own side padding.
- Merges any incoming `className` with its own `droppy-PageSection` class.

{/* END: general */}

{/* BEGIN: when-to-use */}

## When to use

- A titled row of content on a page that also wants a "view all" or "see more" link next to the
  title — a category carousel, a restaurant list, any horizontally-scrolling section.

## When not to use

- A page's own outer width bound with no heading — use
  [Container](?path=/docs/layout-structure-container--docs) directly.
- A raised, self-contained surface — use [Card](?path=/docs/media-content-card--docs) for a tile or
  panel instead of a full-width section.

{/* END: when-to-use */}

## How it works

### Title only

Without `topButtonLabel`, only the heading renders — no empty space is reserved for a button that
isn't there.

<Canvas of={PageSectionStories.Default} />

### With an action

`topButtonLabel` renders a `clear` `Button` on the opposite side of the heading, wired to
`onTopButtonClick`.

## Keyboard & screen reader

`PageSection` itself is a non-interactive layout element — the wrapping `div`s carry no role and
no keyboard behavior of their own.

- **ARIA:** none on the section wrapper; the heading is a native `<h2>`, and the optional button
  is a real [Button](?path=/docs/actions-button--docs) with its own focus and activation
  behavior.
- **Screen reader:** the heading announces as a level-2 heading, so it shows up in a heading-level
  page scan; the button announces its label.
- **You must provide:** a `title` that makes sense read out of context — screen reader users often
  jump between headings rather than reading the page in order.

## Styling

| Token           | Used for                                           |
| --------------- | -------------------------------------------------- |
| `--ds-space-xs` | Padding below the 1024px breakpoint                |
| `--ds-space-sm` | Padding at and above 1024px; gap under the heading |

1600px and the 1024px breakpoint are literal values — no token in the current scale matches them
exactly.

`className` merges with the component's own `droppy-PageSection` class.

## Decision log

- **2026-07**: PageSection kept Mealdrop's API unchanged through the Droppy migration — a required `title` rendered as a level-2 heading plus an optional top-right action via `topButtonLabel`/`onTopButtonClick` that renders a clear Button — and was adopted as a drop-in with no parity deltas ([migration commit](https://github.com/yannbf/mealdrop/commit/dea29009cb06ec78eb7e2c52f216da78d913e747)).
- **Built on [Heading](?path=/docs/typography-heading--docs) and.** Droppy supplies the props, the theme classes, and the copy around it.

## Known issues & open questions

- [#93](https://github.com/yannbf/droppy-ds/issues/93): onTopButtonClick is typed () =&gt; void but is invoked with the click MouseEvent at runtime. **Workaround:** always wrap handlers with parameters (onTopButtonClick=&#123;() =&gt; refetch()&#125;), and use a capture-phase wrapper element when the event itself is needed.
- [#95](https://github.com/yannbf/droppy-ds/issues/95): the documented "view all" action can only render as a &lt;button&gt; — no href or element escape hatch for navigation. **Workaround** (partial): omit topButtonLabel and render your own &lt;a&gt; via the global classes/relative root, or accept button semantics and navigate in onTopButtonClick.
- [#97](https://github.com/yannbf/droppy-ds/issues/97): root div forces height: 100%, so stacked sections stretch to full parent height inside definite-height panes. **Workaround:** pass a className and set height: auto in app CSS (style prop is unavailable), or avoid definite-height ancestors.
- [#98](https://github.com/yannbf/droppy-ds/issues/98): no programmatic link between the action button and the section title; closed props make ARIA disambiguation impossible. **Workaround:** make each label self-describing (e.g. "View all sushi restaurants") — no ARIA channel exists.
- [#100](https://github.com/yannbf/droppy-ds/issues/100): docs claim "side padding" below 1024px, but right padding is 0 — the action button sits flush against the right edge on mobile. **Workaround:** add padding-right: var(--ds-space-xs) below 1024px via a merged className, or give scrolling children trailing padding.
- [#101](https://github.com/yannbf/droppy-ds/issues/101): desktop side inset (1.5rem) does not match default Container's (4rem), so composed content edges misalign. **Workaround:** pair PageSection with Container desktopOnly (same 1.5rem inset), or override padding-inline in app CSS.
- [#103](https://github.com/yannbf/droppy-ds/issues/103): heading level is hardcoded to h2 with no override, so the component cannot fit outlines where another level is correct. **Workaround:** recompose the markup with the global droppy-PageSection classes plus Heading level=&#123;n&#125; size=&#123;2&#125; and Button clear.
- [#104](https://github.com/yannbf/droppy-ds/issues/104): action button is gated solely on topButtonLabel truthiness — label and handler are unpaired, and an empty-string label removes the button. **Workaround:** always pass label+handler together and use topButtonLabel=&#123;label || undefined&#125; for dynamic strings.
- [#106](https://github.com/yannbf/droppy-ds/issues/106): A long unbroken title overflows the section — no min-width or overflow-wrap guard on the heading flex item. **Workaround:** app CSS setting min-width: 0 and overflow-wrap: anywhere on the heading (plus white-space: nowrap on the button), or truncate the title in app code.
- [#125](https://github.com/yannbf/droppy-ds/issues/125): the prop type is a closed set, so `id`/`data-testid`/`aria-*`/`style`/event handlers never reach the rendered DOM.
