# PageSection

{/* BEGIN: when-to-use */}

## When to use

- A titled row of content on a page that also wants a "view all" or "see more" link next to the
  title — a category carousel, a restaurant list, any horizontally-scrolling section.

## When not to use

- A page's own outer width bound with no heading — use
  [Container](?path=/docs/layout-structure-container--docs) directly.
- A raised, self-contained surface — use [Card](?path=/docs/media-content-card--docs) for a tile or
  panel instead of a full-width section.

{/* END: when-to-use */}

{/* BEGIN: anatomy */}

## Anatomy

A title row above caller-supplied content. The row holds the heading and, when a label is given, one `clear` Button.

<Canvas of={PageSectionStories.Anatomy} />

| Part   | `data-part` | Renders    | Purpose                                                     |
| :----- | :---------- | :--------- | :---------------------------------------------------------- |
| Root   | `root`      | `<div>`    | The section: title row above, content below                 |
| Top    | `top`       | `<div>`    | The title row — heading one side, optional action the other |
| Title  | `title`     | `<h2>`     | The section heading                                         |
| Action | `action`    | `<button>` | Rendered only when `topButtonLabel` is set                  |

{/* END: anatomy */}
