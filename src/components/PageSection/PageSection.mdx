# PageSection

{/* BEGIN: anatomy */}

## Anatomy

A title row above caller-supplied content. The row holds the heading and, when a label is given, one `clear` Button.

<Canvas of={PageSectionStories.Anatomy} />

| Part   | `data-part` | Renders    | Purpose                                                     |
| :----- | :---------- | :--------- | :---------------------------------------------------------- |
| Root   | `root`      | `<div>`    | The section: title row above, content below                 |
| Top    | `top`       | `<div>`    | The title row — heading one side, optional action the other |
| Title  | `title`     | `<h2>`     | The section heading                                         |
| Action | `action`    | `<button>` | Rendered only when `topButtonLabel` is set                  |

{/* END: anatomy */}

## Keyboard & screen reader

`PageSection` itself is a non-interactive layout element — the wrapping `div`s carry no role and
no keyboard behavior of their own.

- **ARIA:** none on the section wrapper; the heading is a native `<h2>`, and the optional button
  is a real [Button](?path=/docs/actions-button--docs) with its own focus and activation
  behavior.
- **Screen reader:** the heading announces as a level-2 heading, so it shows up in a heading-level
  page scan; the button announces its label.
- **You must provide:** a `title` that makes sense read out of context — screen reader users often
  jump between headings rather than reading the page in order.
