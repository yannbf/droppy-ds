# PageSection

{/* BEGIN: anatomy */}

## Anatomy

A title row above caller-supplied content. The row holds the heading and, when a label is given, one `clear` Button.

<Canvas of={PageSectionStories.Anatomy} />

| Part   | `data-part` | Renders    | Purpose                                                     |
| :----- | :---------- | :--------- | :---------------------------------------------------------- |
| Root   | `root`      | `<div>`    | The section: title row above, content below                 |
| Top    | `top`       | `<div>`    | The title row — heading one side, optional action the other |
| Title  | `title`     | `<h2>`     | The section heading                                         |
| Action | `action`    | `<button>` | Rendered only when `topButtonLabel` is set                  |

{/* END: anatomy */}

{/* BEGIN: do-dont */}

## Do's and don'ts

### Do

- Write a `title` that makes sense read out of context: it renders as an `<h2>`, and screen reader
  users jump between headings
- Name the top action for where it goes, e.g. "See all Italian" rather than "View all"; nothing in
  the markup ties it to the section title
- Keep one `PageSection` per topic, so the page's `<h2>`s form a readable outline

### Don't

- Don't reach for `PageSection` where an `<h2>` would break the page outline; its heading level is
  fixed
- Avoid a `title` long enough to wrap on mobile: it shares its row with the action button
