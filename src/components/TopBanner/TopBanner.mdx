# TopBanner

{/* BEGIN: when-to-use */}

## When to use

- The header band of a page that wants a large title over either a flat brand color or a hero
  photo — a category list, a restaurant detail page, a confirmation screen.

## When not to use

- A section title inline with the rest of the page's content — use
  [PageSection](?path=/docs/layout-structure-pagesection--docs) instead; `TopBanner` is a full-width
  band meant to sit above the page's content column, not inside it.

{/* END: when-to-use */}

{/* BEGIN: anatomy */}

## Anatomy

A band with an optional heading. Both are optional: with neither `title` nor `photoUrl` the band renders empty.

<Canvas of={TopBannerStories.Anatomy} />

| Part  | `data-part` | Renders | Purpose                                                        |
| :---- | :---------- | :------ | :------------------------------------------------------------- |
| Root  | `root`      | `<div>` | The band, carrying the background image when `photoUrl` is set |
| Title | `title`     | `<h2>`  | Switched to its on-photo treatment when there is a photo       |

{/* END: anatomy */}
