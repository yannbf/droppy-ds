# TopBanner

{/* BEGIN: anatomy */}

## Anatomy

A band with an optional heading. Both are optional: with neither `title` nor `photoUrl` the band renders empty.

<Canvas of={TopBannerStories.Anatomy} />

| Part  | `data-part` | Renders | Purpose                                                        |
| :---- | :---------- | :------ | :------------------------------------------------------------- |
| Root  | `root`      | `<div>` | The band, carrying the background image when `photoUrl` is set |
| Title | `title`     | `<h2>`  | Switched to its on-photo treatment when there is a photo       |

{/* END: anatomy */}

{/* BEGIN: do-dont */}

## Do's and don'ts

### Do

- Write a `title` whose meaning doesn't depend on the photo: `photoUrl` paints a CSS background,
  which is never exposed to assistive tech
- Pick a `photoUrl` dark enough across its upper area for white text, as the on-photo title has no
  scrim behind it
- Keep the banner the only green moment on the screen as per
  [brand guidelines](?path=/docs/brand-guidelines--docs)

### Don't

- Don't count on `TopBanner` for the page's `<h1>`: its title renders at `<h2>`, so the top-level
  heading has to live elsewhere
- Avoid a `title` long enough to wrap, as wrapped lines abandon the centred layout the band is
  built around

{/* END: do-dont */}
