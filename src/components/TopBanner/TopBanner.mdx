## Anatomy

A band with an optional heading. Both are optional: with neither `title` nor `photoUrl` the band renders empty.

<Canvas of={TopBannerStories.Anatomy} />

| Part  | `data-part` | Renders | Purpose                                                        |
| :---- | :---------- | :------ | :------------------------------------------------------------- |
| Root  | `root`      | `<div>` | The band, carrying the background image when `photoUrl` is set |
| Title | `title`     | `<h2>`  | Switched to its on-photo treatment when there is a photo       |
