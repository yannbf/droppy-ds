# TopBanner

{/* BEGIN: anatomy */}

## Anatomy

A band with an optional heading. Both are optional: with neither `title` nor `photoUrl` the band renders empty.

<Canvas of={TopBannerStories.Anatomy} />

| Part  | `data-part` | Renders | Purpose                                                        |
| :---- | :---------- | :------ | :------------------------------------------------------------- |
| Root  | `root`      | `<div>` | The band, carrying the background image when `photoUrl` is set |
| Title | `title`     | `<h2>`  | Switched to its on-photo treatment when there is a photo       |

{/* END: anatomy */}

{/* BEGIN: brand */}

## Brand

Promo and top banners are among soft green's few canonical "good news" sites in the
[brand guidelines](?path=/docs/brand-guidelines--docs): the banner is a soft green surface
carrying dark text, per "Accents are surfaces, not ink". The guidelines' warning applies
directly here — "if a screen has more than one green moment, one of them is probably wrong" —
so a screen with a `TopBanner` shouldn't add other soft-green accents.
