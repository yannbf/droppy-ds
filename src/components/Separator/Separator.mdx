# Separator

{/* BEGIN: anatomy */}

## Anatomy

`Separator` is a single-part component: one `<div>` with `role="separator"` and no children. The caller sizes it — width or height in CSS — to read visually as a line.

<Canvas of={SeparatorStories.Anatomy} />

| Part | `data-part` | Renders | Purpose                                                                              |
| :--- | :---------- | :------ | :----------------------------------------------------------------------------------- |
| Root | `root`      | `<div>` | The divider, carrying `role="separator"`, `aria-orientation`, and `data-orientation` |

{/* END: anatomy */}

## API reference

<ArgTypes of={SeparatorStories} />

### `orientation`

Drives `aria-orientation` and `data-orientation` together, so styling by `[data-orientation]` never
needs the prop value duplicated in your own class logic.

<Canvas of={SeparatorStories.Orientation} />

### `className`

Merged onto the root alongside the component's own `droppy-Separator` class.
