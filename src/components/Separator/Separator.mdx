# Separator

{/* BEGIN: when-to-use */}

## When to use

- A plain visual and semantic break between two blocks or groups of content — a form's sections,
  a toolbar's clusters of controls, a row of inline links.

## When not to use

- Between distinct pages or major layout regions — use a heading, a `Card` boundary, or layout
  spacing instead; a separator is for dividing content within one region, not for structuring the
  page itself.

{/* END: when-to-use */}

{/* BEGIN: anatomy */}

## Anatomy

`Separator` is a single-part component: one `<div>` with `role="separator"` and no children. The caller sizes it — width or height in CSS — to read visually as a line.

<Canvas of={SeparatorStories.Anatomy} />

| Part | `data-part` | Renders | Purpose                                                                              |
| :--- | :---------- | :------ | :----------------------------------------------------------------------------------- |
| Root | `root`      | `<div>` | The divider, carrying `role="separator"`, `aria-orientation`, and `data-orientation` |
