# Modal

{/* BEGIN: when-to-use */}

## When to use

- A single decision that should block the rest of the page until it's made — the `Open` story's "Remove from cart?" confirmation is the shape: state the consequence, offer a way out.
- A short, self-contained task that doesn't need its own page or route — collecting one field before an action runs, as in the README's `Input` + `Button` example.

## When not to use

- To show content the person reviews _alongside_ the page rather than instead of it — a cart, a filter panel, anything they might dip in and out of — use [Sidebar](?path=/docs/overlays-sidebar--docs). Modal takes over the page; Sidebar shares it.
- To explain what a control does before it's activated, use [Tooltip](?path=/docs/overlays-tooltip--docs) — a hint doesn't need a decision or a focus trap.

{/* END: when-to-use */}

{/* BEGIN: anatomy */}

## Anatomy

A backdrop and the dialog card, with a supplied top bar holding the close affordance. Base UI supplies the modal behaviour — focus trap, Escape, outside press, scroll lock, `aria-modal`. The anatomy story portals into a node inside the story canvas via `container`, so the **Anatomy** panel can reach the parts — it only scans the canvas, and the default portal target is the document body.

<Canvas of={ModalStories.Anatomy} />

| Part     | `data-part` | Renders    | Purpose                                               |
| :------- | :---------- | :--------- | :---------------------------------------------------- |
| Backdrop | `backdrop`  | `<div>`    | The dimmed layer behind the dialog                    |
| Popup    | `root`      | `<div>`    | The card: `aria-modal`, the focus trap, and the shape |
| Top bar  | `topbar`    | `<div>`    | Holds the close affordance                            |
| Close    | `close`     | `<button>` | The round icon button that dismisses                  |
