# Modal

{/* BEGIN: anatomy */}

## Anatomy

A backdrop and the dialog card, with a supplied top bar holding the close affordance. Base UI supplies the modal behaviour — focus trap, Escape, outside press, scroll lock, `aria-modal`. The anatomy story portals into a node inside the story canvas via `container`, so the **Anatomy** panel can reach the parts — it only scans the canvas, and the default portal target is the document body.

<Canvas of={ModalStories.Anatomy} />

| Part     | `data-part` | Renders    | Purpose                                               |
| :------- | :---------- | :--------- | :---------------------------------------------------- |
| Backdrop | `backdrop`  | `<div>`    | The dimmed layer behind the dialog                    |
| Popup    | `root`      | `<div>`    | The card: `aria-modal`, the focus trap, and the shape |
| Top bar  | `topbar`    | `<div>`    | Holds the close affordance                            |
| Close    | `close`     | `<button>` | The round icon button that dismisses                  |

## Keyboard & screen reader

| Key                 | Action                                                                                                      |
| ------------------- | ----------------------------------------------------------------------------------------------------------- |
| `Tab` / `Shift+Tab` | Moves focus through the popup's tabbable elements; loops back to the start rather than escaping to the page |
| `Escape`            | Closes the modal                                                                                            |

- **ARIA**: the popup carries `role="dialog"`; the accessible name comes from the `aria-label` prop (default: `"dialog"`).
- **Screen reader**: on open, the dialog is announced using its accessible name; on close, focus returns to wherever it was before the modal opened.
- **You must provide:** a meaningful `aria-label` — the default value is a placeholder, not a real description of the decision being asked. Content inside the modal should also be reachable by Tab; nothing else is required to make it focusable, since the popup itself receives initial focus.
