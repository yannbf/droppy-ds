## Features

- **Focus trap** — Tab loops inside the popup while it's open, so keyboard users can't tab into the page behind it.
- **Scroll lock** — the page behind the modal stops scrolling while it's open.
- **Escape and outside-press dismissal** — closing doesn't need a pointer to hit the close button exactly.
- **Bottom sheet on mobile** — below 768px the popup docks to the bottom edge and slides up instead of appearing centered.
- **Portal by default** — content renders at the end of `document.body`, so a parent's `overflow: hidden` or `z-index` stacking context can't clip or bury it.
- **ARIA dialog wiring** — `role="dialog"` and the accessible name are set for you.

## How it works

### Where focus lands

Focus goes to the popup itself, not the close button: the content is what the reader asked for,
and landing on "close" reads as an invitation to leave. Tab still reaches the close button first.

<Canvas of={ModalStories.InitialFocusIsThePopup} />

### Responsive shape

Below 768px the card becomes a bottom sheet and slides up from the edge.

<Canvas of={ModalStories.Mobile} />

### Open and close motion

Backdrop and popup both transition off `[data-starting-style]` and `[data-ending-style]`, and the
popup stays mounted through the exit so the close animation runs before it disappears.

## Anatomy

A backdrop and the dialog card, with a supplied top bar holding the close affordance. Base UI supplies the modal behaviour — focus trap, Escape, outside press, scroll lock, `aria-modal`. The anatomy story portals into a node inside the story canvas via `container`, so the **Anatomy** panel can reach the parts — it only scans the canvas, and the default portal target is the document body.

<Canvas of={ModalStories.Anatomy} />

| Part     | `data-part` | Renders    | Purpose                                               |
| :------- | :---------- | :--------- | :---------------------------------------------------- |
| Backdrop | `backdrop`  | `<div>`    | The dimmed layer behind the dialog                    |
| Popup    | `root`      | `<div>`    | The card: `aria-modal`, the focus trap, and the shape |
| Top bar  | `topbar`    | `<div>`    | Holds the close affordance                            |
| Close    | `close`     | `<button>` | The round icon button that dismisses                  |
