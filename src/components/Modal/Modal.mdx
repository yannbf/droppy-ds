## Anatomy

A backdrop and the dialog card, with a supplied top bar holding the close affordance. Base UI supplies the modal behaviour — focus trap, Escape, outside press, scroll lock, `aria-modal`. The anatomy story portals into a node inside the story canvas via `container`, so the **Anatomy** panel can reach the parts — it only scans the canvas, and the default portal target is the document body.

<Canvas of={ModalStories.Anatomy} />

| Part     | `data-part` | Renders    | Purpose                                               |
| :------- | :---------- | :--------- | :---------------------------------------------------- |
| Backdrop | `backdrop`  | `<div>`    | The dimmed layer behind the dialog                    |
| Popup    | `root`      | `<div>`    | The card: `aria-modal`, the focus trap, and the shape |
| Top bar  | `topbar`    | `<div>`    | Holds the close affordance                            |
| Close    | `close`     | `<button>` | The round icon button that dismisses                  |

## API reference

<ArgTypes of={ModalStories} />

### `isOpen` and `onClose`

Fully controlled — the component holds no open state of its own. `onClose` fires for the button,
Escape, and an outside press alike.

<Canvas of={ModalStories.IsOpen} />

### `children`

The dialog body; the top bar and its close button are supplied.

<Canvas of={ModalStories.Children} />

### `aria-label`

Names the dialog, since the body has no guaranteed heading.

<Canvas of={ModalStories.AriaLabel} />

### `container`

Where to portal — an element or a selector. Mealdrop portals into its own `#modal` node; a package
can't assume that exists, so it became a prop (docs/MEALDROP-PARITY.md).

<Canvas of={ModalStories.Container} />

### `className`

Merged onto the popup alongside the component's own `droppy-Modal` class.

<Canvas of={ModalStories.ClassName} />
