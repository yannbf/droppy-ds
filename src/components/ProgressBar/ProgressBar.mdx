# ProgressBar

{/* BEGIN: general */}

A track-and-fill indicator for progress through a known number of steps — a multi-step checkout,
an upload, a form with a fixed page count.

```tsx
import { ProgressBar } from '@droppy/design-system'
```

<Canvas of={ProgressBarStories.Default} />

## Features

- `value` and `max` (default `100`) describe how far along the track the fill sits; `value` is
  clamped to `0`–`max` before it reaches the DOM, so an out-of-range prop can't overflow or
  invert the fill.
- `label` sets the accessible name on the track — the title and step copy around the bar
  ("Step 2 of 3") stay the caller's own markup, same as Mealdrop's `StepIndicator`.
- The fill's width transitions on change, so incrementing `value` sweeps rather than jumps.
- Merges any incoming `className` with its own `droppy-ProgressBar` class.

{/* END: general */}

{/* BEGIN: behavior */}

## How it works

A value past `max` clamps rather than overflowing the track, so a caller that counts one step too
far still renders a full bar instead of a broken one — and `aria-valuenow` reports the clamped
number, not the raw one.

## Anatomy

Two parts: the track carries the `progressbar` role and the whole ARIA range, and the fill is a plain width-driven sibling underneath it with no semantics of its own. There is no label part — the copy around the bar is the caller's own markup.

<Canvas of={ProgressBarStories.Anatomy} />

| Part | `data-part` | Renders | Purpose                                                              |
| :--- | :---------- | :------ | :------------------------------------------------------------------- |
| Root | `root`      | `<div>` | `role="progressbar"` with `aria-valuenow`/`-min`/`-max` and the name |
| Fill | `fill`      | `<div>` | The width-driven bar; purely visual                                  |
