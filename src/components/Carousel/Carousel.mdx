# Carousel

{/* BEGIN: when-to-use */}

## When to use

- A horizontally browsable row of same-shaped items where showing a fixed count per breakpoint
  matters more than showing everything at once — a restaurant list, a category rail.

## When not to use

- A small, fixed set of items that all fit comfortably in the available width — a plain flex or
  grid row needs no carousel machinery.

{/* END: when-to-use */}

{/* BEGIN: anatomy */}

## Anatomy

A rail wrapping a clipped viewport and the track inside it, one wrapper per child, with the arrows as siblings of the viewport. The per-breakpoint counts reach the CSS as custom properties rather than inline widths, so the stylesheet owns the breakpoints.

<Canvas of={CarouselStories.Anatomy} />

| Part      | `data-part` | Renders    | Purpose                                                    |
| :-------- | :---------- | :--------- | :--------------------------------------------------------- |
| Root      | `root`      | `<div>`    | Carries the item counts as CSS custom properties           |
| Viewport  | `viewport`  | `<div>`    | The clipped window Embla drives                            |
| Container | `container` | `<div>`    | The track that slides horizontally                         |
| Slide     | `slide`     | `<div>`    | One wrapper per child; dims when not almost fully in view  |
| Nav       | `nav`       | `<button>` | Previous/next; mounted only when that direction can scroll |

{/* END: anatomy */}
