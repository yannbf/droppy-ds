# Input

{/* BEGIN: anatomy */}

## Anatomy

A field root wrapping a label, the control, and an always-mounted error slot. The slot is the unusual part: it stays in the DOM holding a non-breaking space when there is no message, which is what reserves the height.

<Canvas of={InputStories.Anatomy} />

| Part    | `data-part` | Renders   | Purpose                                                          |
| :------ | :---------- | :-------- | :--------------------------------------------------------------- |
| Root    | `root`      | `<div>`   | Base UI's `Field.Root`, wiring label, control and error together |
| Label   | `label`     | `<label>` | Absent when `label` is empty                                     |
| Control | `control`   | `<input>` | The control itself; `className` lands here                       |
| Error   | `error`     | `<div>`   | Always mounted, so showing a message never moves the layout      |

{/* END: anatomy */}

## API reference

<ArgTypes of={InputStories} />

### `label`

Both the visible label and the control's accessible name.

<Canvas of={InputStories.Label} />

### `error`

Fills the reserved slot beneath the control, and is wired to the input via `aria-describedby`.

<Canvas of={InputStories.Error} />

### `type`

Native, and passed straight through — along with every other `<input>` attribute.

<Canvas of={InputStories.Types} />

### `disabled`

Native too; `Field` dims the label alongside the control.

<Canvas of={InputStories.Disabled} />

### `placeholder`

A hint, never a substitute for the label.

<Canvas of={InputStories.Placeholder} />

### `className`

Merged onto the **control**, not the field root, alongside the component's own `droppy-Input`
class.

<Canvas of={InputStories.ClassName} />
