# Input

{/* BEGIN: anatomy */}

## Anatomy

A field root wrapping a label, the control, and an always-mounted error slot. The slot is the unusual part: it stays in the DOM holding a non-breaking space when there is no message, which is what reserves the height.

<Canvas of={InputStories.Anatomy} />

| Part    | `data-part` | Renders   | Purpose                                                          |
| :------ | :---------- | :-------- | :--------------------------------------------------------------- |
| Root    | `root`      | `<div>`   | Base UI's `Field.Root`, wiring label, control and error together |
| Label   | `label`     | `<label>` | Absent when `label` is empty                                     |
| Control | `control`   | `<input>` | The control itself; `className` lands here                       |
| Error   | `error`     | `<div>`   | Always mounted, so showing a message never moves the layout      |

{/* END: anatomy */}

## Do's and don'ts

### Do

- Always pass `label`: with none, no label element renders at all and the field has no accessible
  name
- Write `error` as what to do about it, e.g. "Enter a postcode like SW1A 1AA" rather than
  "Invalid"
- Set `autoComplete` explicitly on fields a browser should fill, e.g. name, email or address; the
  component defaults it to "off"

### Don't

- Don't use `placeholder` in place of `label`: it disappears the moment someone types, taking the
  field's meaning with it
- Avoid stacking more than one message into `error`; the reserved slot holds one short line, and
  longer text pushes the fields below it down

{/* END: do-dont */}
