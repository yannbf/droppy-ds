# QuantityStepper

{/* BEGIN: anatomy */}

## Anatomy

A named group holding two round buttons around a live value. There is no text input — for a typeable amount reach for [NumberField](?path=/docs/forms-input-numberfield--docs) instead.

<Canvas of={QuantityStepperStories.Anatomy} />

| Part      | `data-part` | Renders    | Purpose                                                 |
| :-------- | :---------- | :--------- | :------------------------------------------------------ |
| Root      | `root`      | `<div>`    | The `role="group"` wrapper carrying the accessible name |
| Decrement | `decrement` | `<button>` | The minus; disabled at `min`                            |
| Value     | `value`     | `<span>`   | The quantity, `aria-live="polite"`                      |
| Increment | `increment` | `<button>` | The plus; disabled at `max`                             |

## Keyboard & screen reader

Both buttons are real `<button>` elements — standard Tab/Enter/Space behaviour applies, no custom
key handling.

- **ARIA:** the root is `role="group"` with `aria-label` (default `"quantity"`); the value text
  carries `aria-live="polite"`; each button carries its own `aria-label`
  ("increase/decrease quantity by one").
- **Screen reader:** a change to the value is announced via the live region without needing focus
  to move; the group's label frames the two buttons and the value as one control.
- **You must provide:** a more specific `aria-label` when the default `"quantity"` is ambiguous —
  for example when more than one stepper appears on the same screen.
