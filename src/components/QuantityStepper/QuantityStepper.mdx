# QuantityStepper

{/* BEGIN: general */}

A minus/plus pair flanking a quantity, for adjusting the count of a single item — a food order's
line, a cart quantity.

```tsx
import { QuantityStepper } from '@droppy/design-system'
```

and a [Body](?path=/docs/typography-body--docs) for the value.

<Canvas of={QuantityStepperStories.Default} />

## Features

- `value` and `onChange` are both required — the component holds no state of its own; the caller
  owns the quantity, same as Mealdrop's inline version in `FoodItemModal`.
- `min` (default `1`) and `max` (default `10`) disable the matching button once reached, rather
  than clamping the value or wrapping around.
- The value text carries `aria-live="polite"`, so a change announces itself — the group has no
  other way to signal that a click landed.
- The whole control is a labelled `group` (`aria-label` defaults to `"quantity"`), so assistive
  tech reads the two buttons and the value as one unit.
- Merges any incoming `className` with its own `droppy-QuantityStepper` class.

{/* END: general */}

## How it works

The buttons disable at the bounds rather than wrapping or clamping silently, so a click never
looks like it did nothing. The value carries `aria-live="polite"`, because a disabled button and a
changed number are the only signals the group gives — there is no input to announce itself.

## Anatomy

A named group holding two round buttons around a live value. There is no text input — for a typeable amount reach for [NumberField](?path=/docs/forms-input-numberfield--docs) instead.

<Canvas of={QuantityStepperStories.Anatomy} />

| Part      | `data-part` | Renders    | Purpose                                                 |
| :-------- | :---------- | :--------- | :------------------------------------------------------ |
| Root      | `root`      | `<div>`    | The `role="group"` wrapper carrying the accessible name |
| Decrement | `decrement` | `<button>` | The minus; disabled at `min`                            |
| Value     | `value`     | `<span>`   | The quantity, `aria-live="polite"`                      |
| Increment | `increment` | `<button>` | The plus; disabled at `max`                             |
