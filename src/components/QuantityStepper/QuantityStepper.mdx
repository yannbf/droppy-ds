## Anatomy

A named group holding two round buttons around a live value. There is no text input — for a typeable amount reach for [NumberField](?path=/docs/forms-input-numberfield--docs) instead.

<Canvas of={QuantityStepperStories.Anatomy} />

| Part      | `data-part` | Renders    | Purpose                                                 |
| :-------- | :---------- | :--------- | :------------------------------------------------------ |
| Root      | `root`      | `<div>`    | The `role="group"` wrapper carrying the accessible name |
| Decrement | `decrement` | `<button>` | The minus; disabled at `min`                            |
| Value     | `value`     | `<span>`   | The quantity, `aria-live="polite"`                      |
| Increment | `increment` | `<button>` | The plus; disabled at `max`                             |
