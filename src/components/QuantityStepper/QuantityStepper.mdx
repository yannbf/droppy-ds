# QuantityStepper

## Anatomy

A named group holding two round buttons around a live value. There is no text input — for a typeable amount reach for [NumberField](?path=/docs/forms-input-numberfield--docs) instead.

<Canvas of={QuantityStepperStories.Anatomy} />

| Part      | `data-part` | Renders    | Purpose                                                 |
| :-------- | :---------- | :--------- | :------------------------------------------------------ |
| Root      | `root`      | `<div>`    | The `role="group"` wrapper carrying the accessible name |
| Decrement | `decrement` | `<button>` | The minus; disabled at `min`                            |
| Value     | `value`     | `<span>`   | The quantity, `aria-live="polite"`                      |
| Increment | `increment` | `<button>` | The plus; disabled at `max`                             |

## Do's and don'ts

### Do

- Give each stepper its own `aria-label` when several share a screen: the group's default name is
  just "quantity", and identical names don't tell a screen reader user which item they are
  changing
- Set `min` to 0 only where zero is a real quantity; where it means "remove", give users a
  separate way to say so
- Show the consequence of a change next to the stepper, e.g. a line total, so the number has a
  visible effect

### Don't

- Don't leave `max` at the default value where real stock or capacity is lower
