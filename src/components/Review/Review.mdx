# Review

{/* BEGIN: anatomy */}

## Anatomy

A wrapper and the text line inside it. The star, the number, and the band label are one string rather than separate parts — there is no per-star markup to target.

<Canvas of={ReviewStories.Anatomy} />

| Part | `data-part` | Renders  | Purpose                                        |
| :--- | :---------- | :------- | :--------------------------------------------- |
| Root | `root`      | `<div>`  | The wrapper the caller positions               |
| Text | `text`      | `<span>` | The score line, in the quiet review text token |

{/* END: anatomy */}

{/* BEGIN: do-dont */}

## Do's and don'ts

### Do

- Hand `rating` over unrounded and let `Review` format it: it renders one decimal place and picks
  the wording ("Very good", "Excellent") from the value
- Leave `rating` unset where nothing has been rated yet; the component says "No reviews yet"
  rather than showing a misleading zero

### Don't

- Don't set `color` to make a rating stand out: the quiet, low-contrast treatment is deliberate,
  and the accent-as-ink exception it already uses isn't meant to be extended
- Avoid placing a `Review` where the thing being rated isn't obvious from the line above it

{/* END: do-dont */}
