## Keyboard & screen reader

`Review` renders static text — there is no keyboard interaction to document.

- **ARIA:** none — the rating and label are read as plain text content.
- **Screen reader:** announced as the rendered string (e.g. "★ 4.5 Very good" or "No reviews yet").
- **You must provide:** nothing further, unless the surrounding context needs an accessible name
  for the region the review sits in.
