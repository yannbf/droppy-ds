# Review

{/* BEGIN: general */}

A star-rating and text line — "★ 4.5 Very good" or "No reviews yet" — for a restaurant tile, an
item card, or an order summary.

```tsx
import { Review } from '@droppy/design-system'
```

<Canvas of={ReviewStories.Default} />

## Features

- `rating` is a number out of 5. It maps to one of four labels — "Very poor" below 2, "Adequate"
  from 2 to 4, "Very good" from 4 to 5, "Excellent" at 5 — prefixed with the star glyph and the
  rating to one decimal place.
- No `rating` (or a falsy one) renders "No reviews yet" instead of a score.
- Uses the low-contrast `--ds-color-text-review` token by default — a deliberately quiet
  treatment so the rating reads as secondary to the content around it. Pass `color` to override it.
- Merges any incoming `className` with its own `droppy-Review` class.

{/* END: general */}

{/* BEGIN: behavior */}

## How it works

### Rating bands

The bands are fixed: under 2 is "Very poor", 2–4 "Adequate", 4–5 "Very good", and exactly 5
"Excellent". The number always shows one decimal, so `4` and `4.0` read identically.

<Canvas of={ReviewStories.RatingBands} />

### No rating

A missing or falsy `rating` renders a plain fallback line rather than a zero-star score, so a
newly-listed restaurant doesn't look badly reviewed.

## Anatomy

A wrapper and the text line inside it. The star, the number, and the band label are one string rather than separate parts — there is no per-star markup to target.

<Canvas of={ReviewStories.Anatomy} />

| Part | `data-part` | Renders  | Purpose                                        |
| :--- | :---------- | :------- | :--------------------------------------------- |
| Root | `root`      | `<div>`  | The wrapper the caller positions               |
| Text | `text`      | `<span>` | The score line, in the quiet review text token |
