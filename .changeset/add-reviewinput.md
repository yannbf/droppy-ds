Add ReviewInput: an editable star rating and review-text field, for rating something already received — a past order, a delivered item — as opposed to Review, which only displays an aggregate score. The rating is a real radiogroup (arrow keys move and select, each star labelled "N of 5 stars"); the review text reuses Field, the same label wiring Input and NumberField are built on.
